# UniGen-AR: Unifying Visual Generation with Auto-Regressive Modeling

**Authors**: Zhipeng Bao, Zhen Zhu, Nupur Kumari, Anurag Bagchi, Yu-Xiong Wang, Pavel Tokmakov, Martial Hebert
**Venue**: arXiv
**Link**: https://arxiv.org/abs/2607.24157
**PDF**: https://arxiv.org/pdf/2607.24157
**Importance**: 高优先级 (96.2)
**Why selected**: Directly advances the user’s top-priority continuous language model and autoregressive visual generation subtopics with a unified, efficient framework. Signals: autoregressive visual generation, unified multimodal model, efficient inference, continuous visual token, VAR decoder
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

UniGen-AR 首次将多模态大语言模型与 next-scale 视觉自回归解码器结合，实现覆盖 15+ 任务的统一视觉生成，推理延迟比扩散模型基线降低最高 19 倍，同时保持或提升生成质量。  
UniGen-AR pairs a multimodal LLM with an efficient visual autoregressive decoder to achieve unified visual generation across 15+ tasks, delivering up to 19× lower inference latency than diffusion baselines while maintaining or improving output quality.

---

## 动机 / Motivation

### 中文概述
- **解决的问题**：当前视觉生成流水线高度碎片化（文生图、编辑、修复、经典感知任务由分立模型处理），最近兴起**统一视觉生成 (UVG)** 范式，但主流 UVG 系统基于扩散模型，其迭代去噪过程导致推理延迟极高（需数十步），限制实际部署。  
- **现有工作的 gap**：扩散模型虽然质量和可控性强，但推理效率低下，难以扩展；之前的自回归 (AR) 方法在视觉生成上质量不足，而新兴的 **VAR（next-scale visual autoregressive）** 虽然高效且具有潜在空间统一优势（自然图像与结构输出如深度图可共用离散 token 空间），但缺乏灵活的指令跟随能力。  
- **关键出发点**：VAR 的**粗到细解码**只需少量生成阶段即可达到与扩散模型相当的感知质量，且支持潜在空间统一，若能配合强大的多模态前端处理指令与多模态输入，有望构建**高效率和高质量兼顾的 UVG 系统**。

### English Summary
The paper addresses the fragmentation in visual generation pipelines and the high inference latency of diffusion‑based UVG systems. It targets the gap where VAR models are efficient and enable latent unification for diverse visual outputs but lack flexible instruction‑following. The key insight is to combine a general‑purpose MLLM with a VAR decoder to achieve both efficient sampling and multimodal control.

## 核心方法 / Core Method

### 中文概述
- **整体框架**：UniGen-AR 将 **MLLM（Qwen2.5‑VL）** 作为多模态前端，将指令文本与参考图像编码为统一的**文本嵌入**；后端使用**基于 Infinity 的 VAR 解码器**，以 next‑scale 方式自回归预测多尺度离散视觉 token。  
- **核心机制**：
  1. **参考与目标 tokenization**：参考图像和目标图像均通过多尺度 VQ‑VAE 编码，但**仅保留参考图像的最精细尺度 token** 作为非预测性的上下文前缀，保持原始 VAR 的粗到细生成进度不变。  
  2. **多模态编码**：MLLM 输出纯文本嵌入，用于生成可学习的 [SoS] token（引导生成开始）并作为 cross‑attention 的 key/value 注入 VAR 解码器各层。  
  3. **统一 token 序列与因果掩码**：将参考 token 前置，后接 [SoS] 和从粗到细的目标 token，使用**块因果掩码**保证所有目标 token 可关注参考与文本上下文，同时保留标准的 VAR 粗到细生成顺序。  
  4. **训练**：采用 teacher‑forcing 的统一似然损失（多尺度交叉熵），位分词器支持大码书。  
- **与最相关工作的区别**：首次将 **MLLM 条件化**与 **next‑scale VAR** 结合覆盖完整 UVG；不同于仅文生图的 Infinity 或仅编辑的 VAREdit，UniGen-AR 支持文生图、感知、修复、编辑四大类共 15+ 任务，无需任务专用头，使用单一模型权重和统一接口。

### English Summary
UniGen-AR pairs a Qwen2.5‑VL MLLM encoder with an Infinity‑style VAR decoder. Reference images are tokenized with only their finest‑scale tokens kept as a non‑predictive prefix, while the MLLM provides text embeddings for cross‑attention and an [SoS] token to seed generation. A block‑wise causal mask unifies the sequence while preserving the coarse‑to‑fine VAR schedule. Training uses a teacher‑forcing likelihood loss over all scales. This is the first framework to combine MLLM conditioning with VAR for full‑spectrum UVG across 15+ tasks.

## 启发性分析 / Insight Analysis

### 中文概述
- **消融实验的发现**：论文特别指出 **VQ‑VAE 分词器的设计（码书大小和层级结构）是 VAR 在 UVG 中可扩展性的关键因素**。大的码书（如 Infinity 的 bitwise tokenizer）带来了更精细的重建和更丰富的视觉细节，直接提升了多任务生成质量。  
- **反直觉或值得注意的发现**：
  - 参考图像**仅使用最精细尺度 token** 即足够支持 UVG 任务，无需所有尺度，这一设计在维持原有 VAR 生成计划的同时大幅节省了上下文长度。  
  - 延迟‑质量帕累托前沿显示，自回归解码在各步数下均优于扩散模型采样，即使在相同推理预算下也能取得更好的质量。  
- **缩放与泛化见解**：论文暗示 VAR 潜在的缩放定律（参考 Infinity 的发现）在 UVG 场景下依然有效，但需要大码书和合理层级设计；MLLM 的条件化能力与 VAR 的解码效率可以协同缩放。

### English Summary
Ablations highlight that VQ‑VAE tokenizer design—especially codebook size and hierarchy—is critical for VAR scalability in UVG. A counterintuitive finding is that only the finest‑scale reference tokens are needed for image‑conditioned tasks, preserving efficiency. The latency‑quality Pareto frontier consistently favors autoregressive decoding over diffusion sampling.

## 局限性与展望 / Limitations & Future Work

### 中文概述
- **作者承认的局限性**：文中未明确列出局限性章节，但隐含的局限包括：依赖预训练 VAR 模型（Infinity）和 MLLM，训练数据规模相对较小（LAION 子集 + 20 万感知图像），可能限制了更大规模下的泛化；VQ‑VAE 重建可能丢失细节（尽管大码书缓解）。  
- **未提及的重要局限**：目前仅覆盖图像任务，未涉及视频或 3D；参考图像仅用最精细尺度 token 可能丢失多尺度的上下文信息，在需要精细结构感知的任务上可能有潜在性能上限；位分词器增加了计算开销；缺乏与最新扩散模型（如 Flux 等更大模型）的公平大规模比较。  
- **未来方向**：扩展到视频生成或 3D 内容生成；设计更专门的 VQ‑VAE 或连续 tokenizer 以进一步提升质量；结合更强的 MLLM 或更大规模训练；研究统一模型对理解与生成任务的双向能力。

### English Summary
Limitations include reliance on pre‑trained backbones, moderate training data, and possible fidelity loss from VQ‑VAE. Unmentioned issues: lack of video/3D extension, potential information loss from using only finest‑scale reference tokens. Future work may scale to larger models, broader modalities, and improve tokenizers.

## 个人思考 / Personal Takeaways

- **框架价值**：UniGen-AR 为 UVG 提供了一种**极简且高效的设计范式**——“预训练 VAR 骨干 + 即插即用的 MLLM 前端”，无需任务专用头，统一似然训练，对后续多任务视觉生成系统有直接启发。  
- **关键设计点**：  
  - 使用**仅最精细尺度参考 token** 的策略既简单又有效，提示在统一生成中，对齐图像条件的方式不一定需要全尺度特征，未来也可尝试用轻量级适配器融合更丰富的参考信息。  
  - **位分词器**带来的大码书是 VAR 走向高质量生成的核心，未来研究可进一步探索更先进的离散或连续视觉 tokenizer 如何影响 AR 统一模型。  
- **可扩展性**：该架构的 MLLM 和 VAR 完全解耦，未来可分别独立升级（如换成更强大的 LLM，或更快的 VAR 解码器），易于跟进各自领域的最新技术。  
- **潜在研究方向**：引入**连续视觉 token** 替代离散 token 以保留更多细节，同时利用 AR 解码效率；或将其与**统一多模态理解‑生成**模型结合，实现类似 GPT‑4o 的图像理解与生成能力于一身。  
- **批判性观察**：虽然推理延迟大幅降低，但该比较是在“匹配条件化”下进行的，实际部署中 MLLM 前向计算也占时，未完全量化端到端延迟；且图像生成质量与 SOTA 扩散模型（如 Flux）是否仍存在差距，需进一步看其数值指标。

# Rethinking the Generation Order of Block Diffusion Language Models

**Authors**: Kai Syun Hou, James Kwok  
**Venue**: arXiv  
**Link**: https://arxiv.org/abs/2607.24306  
**PDF**: https://arxiv.org/pdf/2607.24306  
**Importance**: 高优先级 (95.24)  
**Why selected**: Directly advances continuous language model generation efficiency, a top-priority subtopic, with a novel training-free parallel decoding method. Signals: block diffusion language model, parallel autoregressive decoding, training-free sampling, left-to-right alignment, generation quality vs speed tradeoff  
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

针对块扩散语言模型 (BDLM)，本文发现其天然偏向从左到右解码，提出无需训练的并行自回归解码方法 PARD，在保持近似的生成质量下，显著优于现有并行采样器并大幅提速。

Block diffusion language models (BDLMs) are naturally more aligned with left-to-right decoding; the proposed training-free Parallel Autoregressive Decoding (PARD) preserves this structure while enabling parallel token commitment, consistently outperforming existing parallel samplers with minimal quality loss.

---

## 动机 / Motivation

### 中文概述
- **解决的问题及重要性**：扩散语言模型（DLM），尤其是早期的掩码扩散模型（MDM），支持任意顺序生成，但已有采样方法多针对MDM设计，对最新涌现的块扩散语言模型（BDLM）探索不足。BDLM在训练时明确结合了块间的自回归结构与块内的扩散，具有更强的生成质量和更快的推理速度，但缺乏合适的采样策略。
- **针对的差距**：现有多数并行采样器（如Confidence、Margin、Entropy等）基于任意顺序设计，未考虑BDLM在训练过程中形成的从左到右解码偏好。这导致并行解码时可能牺牲生成质量。
- **关键观察或出发点**：作者通过对比SDAR (BDLM) 和 LLaDA (MDM) 的解掩码位置分布，发现BDLM的生成顺序明显更靠近严格的自回归顺序（对角线集中）。定量指标AR-ness@k同样显示BDLM更符合从左到右。进一步分析训练时的输入上下文差异：MDM几乎从未见过纯AR的左到右上下文，而BDLM在训练中以较高概率观察到此类上下文，导致模型更适应AR式解码。

### English Summary
Recent block diffusion LMs (BDLMs) show strong empirical performance, but their sampling behavior is underexplored—most parallel sampling methods were designed for arbitrary-order MDMs. The authors observe that BDLMs naturally prefer left-to-right decoding (unlike from-scratch MDMs) due to their training context bias, and pure AR sampling can outperform arbitrary-order samplers on BDLMs. This motivates a principled parallel sampling method aligned with the AR bias.

---

## 核心方法 / Core Method

### 中文概述
- **整体框架**：提出并行自回归解码 (Parallel Autoregressive Decoding, PARD)，一种简单的、无需训练的即插即用采样策略，适用于任何已有的任意顺序并行采样器（如基于置信度、边缘置信度、熵等准则）。
- **核心机制**：在每一步解码中，给定一个现有准则（例如置信度阈值），PARD 不直接接受所有通过准则的 token，而是**仅接受从最左侧开始的最长连续已通过准则的 token 前缀**。即，如果某些 token 满足准则但不在最左侧连续前缀中，它们不会被立即提交，从而强制保留全局的从左到右结构。这一操作同时允许该前缀中的所有 token 被并行生成。
- **与最近工作的区别**：不同于APD等依赖外部小模型验证前缀的方法，PARD 直接利用BDLM自身在任一去噪步骤的输出，不引入额外模型或训练。与纯粹基于阈值（如ConfidenceParallel）或复杂子集选择（如KLASS, EB-Sampler）的并行采样器不同，PARD 强调了“前缀约束”作为更有效的结构先验，而非仅仅提高单个token选择的可靠性。

### English Summary
PARD is a training-free plug-and-play method that adapts any arbitrary-order parallel sampler to BDLLMs by only unmasking the longest leftmost prefix of confidently predicted tokens at each step. It preserves the autoregressive structure while keeping parallel decoding capability, without requiring auxiliary models or training modifications.

## 启发性分析 / Insight Analysis

### 中文概述
- **消融与分析揭示的洞见**：
  - **图1与图2的定量结果**：SDAR (BDLM) 的解掩码位置分布在对角线更集中，局部和全局AR-ness@k均显著高于 LLaDA (MDM)，说明BDLM本身已经趋于AR顺序，而MDM的AR偏向较弱。
  - **纯AR vs. 任意顺序采样器的比较**（图3）：在BDLM (SDAR)上，纯AR采样比最佳任意顺序采样器（Entropy）在HumanEval上高出1.9个点；而在MDM (LLaDA)上，纯AR则低4.2个点。这反直觉地表明：**强制AR顺序对于从零训练的MDM反而有害**，但对于从AR模型初始化并采用块扩散目标训练的BDLM却极为有利。
  - **训练上下文分析**（§3.2-3.3）：通过理论概率推演，证明MDM训练中几乎不可能出现纯左到右输入模式（概率极低），而块扩散模型中整个训练上下文偏向AR格式。这一分析揭示了**训练目标的差异直接导致了推理时生成顺序的偏好**。
  - **并行采样的有效性来源**：图5的速度-质量曲线显示，对于多种准则（Confidence, Margin, Entropy），将PARD的前缀约束（即只保留最长连续左前缀）施加于原有并行采样器，都能显著向上移曲线（更高准确率的同时保持或提高吞吐量）。这表明**并行解码中的核心难题不是如何选择更可靠的token，而是如何维持正确的生成顺序**。单纯提高token级置信度（如Margin）不足以并行化，但结合前缀约束后效果突升。
  - **定性分析**（附录D.4）：任意顺序采样器倾向于先提交简单但非左对齐的token，过早锁定程序结构，导致代码生成任务出错；PARD强制从左到右能避免这一问题。

### English Summary
Ablations reveal that BDLLMs are inherently AR-biased due to training context differences, and pure AR decoding works well only on BDLLMs, not on from-scratch MDMs. The key insight is that enforcing a leftmost-prefix constraint (PARD) dramatically improves parallel sampling effectiveness for various confidence criteria, suggesting that preserving generation order is more important than token-level reliability in parallel decoding.

## 局限性与展望 / Limitations & Future Work

### 中文概述
- **作者承认的局限**：仅关注推理时的采样策略，未修改训练目标或采用基于训练的方法（如采样感知微调）。实验受计算资源限制，仅在7B-16B规模的开源BDLM上验证，未在百亿级模型上测试。

- **未来方向**：将PARD与训练时调整结合（如提示调整或强化学习），以进一步提升质量-效率平衡；扩展到更大规模模型；探索在MDM甚至纯自回归模型中的适用性。

### English Summary
The work is limited to inference-time sampling without training modifications, and experiments are restricted to 7–16B BDLMs. Combining PARD with training-based improvements and scaling to larger models are promising future directions, along with exploring task-specific order flexibility.

## 个人思考 / Personal Takeaways

- **创新价值**：该文章从一个简单的经验观察出发（BDLM天生更AR），干净利落地分析原因并提出极简的解决方案（PARD），在保持训练无关的前提下大幅提升现有并行采样器的性能。这种“先理解再设计”的思路在扩散模型采样方法设计中值得借鉴。
- **方法实用性**：PARD即插即用，无需重新训练，可直接作用于已发布的BDLM，工程落地门槛很低。它也可能对其他半自回归生成范式（如多块并行）有启发。
- **可扩展方向**：一个可能的后续工作是，将PARD中的“左连续前缀”约束动态化，即根据不同任务允许灵活的生成顺序（如有时需要从中间或右侧开始），同时保留结构偏差。另外，将PARD与置信度校准训练结合，或许能接近纯AR质量的极限。
- **实验与理论的平衡**：论文兼顾了理论分析（训练上下文概率计算）和实验验证，但这种理论分析较初步，未来可以进一步建模推导BDLM中AR偏好的定量界限。

## 一句话总结 / One-liner

WaveZip 提出一种基于离散小波变换的联合信号-频域框架，通过时空解耦实现视频token的高效压缩，无需额外训练即可在10倍压缩比下保留99.6%的全量性能。  
WaveZip proposes a wavelet-driven joint signal-frequency framework that decouples spatiotemporal token condensation, retaining 99.6% of full performance at 10× compression without task-specific training.

---

## 动机 / Motivation

### 中文概述
现有的Large Vision-Language Models (LVLMs) 处理长视频时，视觉token数量庞大（T × N），导致Transformer注意力的计算复杂度呈二次增长。已有加速方法主要在空间特征域进行硬剪枝（hard pruning）或均匀合并（uniform merging），但这些操作无法解耦低频结构背景和高频判别性语义细节——时间上的帧级相关性序列混叠了缓慢趋势和由噪声、抖动或场景变化引起的高频波动，导致预算分配不稳定；空间上任务相关的细粒度证据与冗余纹理交织，难以单独保留。WaveZip 的核心洞察是：时间冗余主要存在于低频近似尺度，而空间显著性则与高频成分强相关。由此，将token压缩重新建模为一个频率域的解耦问题，分别处理低频结构与高频细节，为高效的预算分配与细节保留提供新范式。

### English Summary
Long-form video understanding in LVLMs suffers from quadratic attention cost due to thousands of visual tokens. Existing compression in the spatial feature domain (hard pruning, uniform merging) conflates low-frequency structure with high-frequency details, causing unstable temporal budget allocation and blurred salient regions. WaveZip reformulates token condensation as frequency-aware decoupling: temporal redundancy lives in low-pass scales, spatial saliency in high-frequency components, enabling joint signal-frequency operation without training.

## 核心方法 / Core Method

### 中文概述
WaveZip 是一个即插即用的训练免框架，包含四个顺序模块：

1. **Cross-Modal Scorer**：使用冻结的轻量跨模态模型（如BLIP-ITM）计算两类信号：(i) 帧级相关性分数 \( r_t \)（通过平均池化后与query的余弦相似度或ITM头输出）；(ii) token级空间显著性图 \( M_t \)（逐token余弦相似度或交叉注意力权重，经秩保留归一化）。该模块仅需编码器部分，无需解码或微调。

2. **Visual Change Estimator (VCE)**：通过相邻帧的空间平均池化特征的余弦距离量化帧间视觉变化 \( \delta_t \)，经min-max归一化得到门控因子 \( \gamma_t \in [0, 1] \)（值越大表示突变）。同时设置阈值 \( \tau \) 滤除冗余帧，保留索引集 \( \mathcal{M} \)。

3. **Wavelet Processor**（双分支）：
   - **Wavelet Temporal Allocator (WTA)**：对帧级相关性序列 \( \{r_m\} \) 做1D DWT分解，得到低频近似系数（趋势）和高频细节系数（波动）。将高频系数与VCE提供的门控 \( \gamma_m \) 逐点相乘（视觉变化大的帧保留高频，静态段压制），再通过逆DWT重构修正的相关性序列 \( \widetilde{r}_m \)，并据此动态分配每帧的token预算 \( n_m \)，总预算 \( B = \sum n_m \)。
   - **Wavelet Spatial Modulator (WSM)**：对保留的每帧特征图 \( X_m \) 做2D DWT（db4小波，一级分解），得到低频近似分量 \( LL \) 和高频细节分量 \( LH, HL, HH \)。利用空间显著性图 \( M_m \) 对高频子带进行重加权（调制），乘上幅度因子 \( \lambda \) 以控制保留程度，低频分量保持不变。重加权后的子带与 \( LL \) 通过逆2D DWT重构出保留细节的特征图。

4. **Token Assigner**：根据分配的帧级预算 \( n_m \)，对重构后的特征图进行自适应下采样（如双线性插值），并通过投影层得到最终压缩的token序列 \( \widetilde{Z} \in \mathbb{R}^{B \times d} \)，送入LLM前缀。

与最相近的工作 Fourier-VLM（对特征做2D DCT统一截断高频）相比，WaveZip 使用局部化的小波分解，显式建模时间和空间两个维度的压缩，且为查询条件化、完全免训练。

### English Summary
WaveZip has four stages: (1) a frozen Cross-Modal Scorer computes frame-level relevance and token-level spatial saliency; (2) Visual Change Estimator gates high-frequency temporal coefficients via inter-frame cosine distance and filters redundant frames; (3) Wavelet Processor: 1D DWT decomposes relevance sequence → gating → inverse DWT to dynamically allocate frame token budgets; 2D DWT decomposes frame features → saliency-modulates high-frequency subbands → inverse DWT to preserve spatial details; (4) Token Assigner downsamples modulated features according to budget and projects them into compact tokens. Unlike Fourier-VLM’s uniform frequency truncation, WaveZip conditions on queries in the decoupled spatial-temporal space without training.

## 启发性分析 / Insight Analysis

### 中文概述
通过系统的消融和定性分析，论文揭示了几个关键现象：

- **小波基选择不敏感**：在Haar、db4、bior4.4三种小波基下，性能值紧密聚类（平均变化范围约0.8%），且不同压缩比下最优基不稳定。这表明WaveZip的增益主要来自多频带解耦机制本身，而非特定小波族的性质，该结论具有反直觉性——通常认为小波特性会影响压缩效果。

- **时间分配与空间调制的互补性**：与仅保留均匀压缩基线（Uniform）相比，单独加入WTA（动态时间预算）就在整体上提升了性能，再加入WSM（空间显著性调制）在VideoMME和LongVideoBench上进一步取得明显增益，而EgoSchema变化较小，说明WTA主要应对长时趋势变化，WSM擅长处理空间细节需求，两者互补覆盖了不同任务。

- **查询相关性更偏向高频细节带**：通过对不同小波子带（LL, LH, HL, HH）与空间显著性图的Pearson相关性分析，发现显著性更多体现在高频细节带，而低频近似带相关性较弱，直接支撑了“高频保留细节、低频维持结构”的设计动机。

- **调制尺度λ的鲁棒性**：λ从0.5变至2.0时性能波动较小（视频MME、LongVideoBench、EgoSchema上仅轻微变化），说明方法对超参数不敏感，易于部署。

- **帧预算扩展性**：在16→128帧的实验（VideoMME + LLaVA-Video）中，WaveZip准确率从54.8%持续上升至62.1%，而FastV、VisionZip在大帧数时OOM，FastVID则性能饱和。这表明WaveZip的频率域分配策略能更好地利用更多帧的信息而不引入额外计算瓶颈。

需要注意的是，论文未提供理论层面的深度分析（如为什么频率解耦在数学上优于空间操作），也未进行误差棒或多随机种子的统计显著性测试。

### English Summary
Ablations reveal: (1) Wavelet basis almost irrelevant—∼0.8% range, gain from multi-band decomposition; (2) WTA (temporal allocation) and WSM (spatial modulation) provide complementary gains across benchmarks; (3) Query-conditioned saliency correlates more strongly with wavelet detail bands (LH/HL/HH) than LL approximation; (4) Modulation scale λ is robust; (5) Accuracy improves with more frames (16→128), while baselines OOM or saturate. No theoretical analysis or statistical error bars are presented.

## 局限性与展望 / Limitations & Future Work

### 中文概述
**作者承认的局限性**：论文中未明确列出limitations段落，但从设计可推知：完全依赖固定的预训练跨模态评分器（如BLIP），其质量直接影响相关性估计，若评分器不匹配任务可能失效；小波基选择虽不敏感，但分解层级固定为一级，可能遗漏多尺度时间冗余；整体方法无学习机制，无法针对特定数据分布自适应优化。

**未提及的重要局限**：  
- 计算代价分析缺失：虽强调免训练，但每次推理需额外进行1D/2D DWT、视觉变化估计和跨模态评分器前向传播，实际时间开销相比baseline未量化，可能抵消token节省的收益。  
- 可解释性局限：频带重加权基于全局显著性图，无法处理局部细微动作或短暂事件的保留。  
- 对密集文本或动态高光的视频，显著性估计可能不准确。  

**未来方向**：  
- 引入多级小波分解或多尺度频域分析，捕捉不同时间尺度的冗余。  
- 将跨模态评分器设计为可学习的轻量模块，或与LVLM联合优化（保持部分端到端能力）。  
- 扩展到更多LVLM骨干，并在更大规模的视频基准（如MVBench、Video-ChatGPT）上验证。  
- 结合token合并策略，在解耦空间中进一步减少冗余头的数量。

### English Summary
Limitations: Fixed pretrained scorer may fail on mismatched tasks; single-level DWT misses multi-scale redundancy; no latency or memory overhead analysis compared to baselines; no statistical error bars. Unmentioned: inability to handle fine-grained short-duration events; extra compute of DWT and cross-modal scorer not quantified. Future work: multi-level wavelet decomposition, learnable scoring modules, larger-scale evaluation, combined token merging in decoupled space.

## 个人思考 / Personal Takeaways

- **创新性与实用性**：将经典信号处理的小波变换引入多模态token压缩，视角新颖且颇具工程价值。训练免的特性使其极易集成到现有LVLM流程中，符合当前“高效即插即用”的研究潮流，对于实际部署意义重大。
- **方法论的启示**：“解耦-分别处理-重构”的思路值得在更多压缩场景中借鉴：未来或许可以推广到傅里叶、学习型频域变换（如FEAST）或基于相位和幅度的分离，以期更精细地保留任务相关的视觉证据。
- **可能的改进方向**：
  - 评分器的联合学习：虽然保持免训练是卖点，但可在下游任务上微调评分器的投影层来适配不同数据分布，并研究是否会影响泛化。
  - 多尺度时间建模：WaveZip目前只分析帧级相关性序列，可考虑在patch级时间序列上也应用1D DWT，实现更细粒度的时空解耦。
  - 与量化或attention缩减技术结合：压缩后的token数量仍较高时，可与token pruning或low-bit quantization搭配，进一步降低吞吐成本。
- **评价的严谨性**：实验设计较为全面，但缺少时间/内存开销对比是一个薄弱点，若后续工作能补充，说服力将更强。此外，在噪声视频或低质量视觉特征上的鲁棒性也值得探索。
- **应用场景联想**：除了视频问答，该方法可被用于长视频摘要、检索或交互式流式推理，作为预处理阶段，平衡速度与精度。
