# WorldDirector: Building Controllable World Simulators with Persistent Dynamic Memory

**Authors**: Hanlin Wang, Hao Ouyang, Qiuyu Wang, Wen Wang, Qingyan Bai, Ka Leong Cheng, Yue Yu, Yixuan Li, Yihao Meng, Zichen Liu, Yanhong Zeng, Yujun Shen, Qifeng Chen

## 一句话总结 / One-liner

WorldDirector 将语义运动编排与视觉生成解耦，利用 LLM 规划 3D 轨迹作为控制信号，构建了具备持久动态对象记忆和自由视点探索能力的可控视频世界模型。
WorldDirector decouples semantic motion orchestration from visual generation, leveraging an LLM-planned 3D trajectory as control signals to construct a controllable video world model with persistent dynamic object memory and free-viewpoint exploration.

---

## 动机 / Motivation

### 中文概述
- 当前视频世界模型普遍将物理动态与像素渲染耦合，依赖连续视觉观测维持运动，导致对象离开视野后出现运动停滞、身份丢失等问题，即缺乏“物体恒存性”和“动态对象记忆”。
- 现有方法中，基于外部监视器的显式追踪扩展性差、计算开销大；依赖生成预知隐式推测轨迹的则在长时间相机偏移或复杂交互下易发生轨迹坍塌、状态冻结。
- 核心观察：要实现真正的持久世界模拟，必须满足两个支柱——对象运动独立于相机可视性持续进行，且重新入画时外观精细度完全不变。现有工作无法兼顾可扩展性与可靠性。
- 由此提出显式解耦运动规划与视频合成，将 LLM 协调的 3D 语义轨迹作为条件注入生成模型，从架构层面保证动态记忆。

### English Summary
The paper addresses the lack of object permanence and dynamic memory in video world models, where entities that leave the camera’s view freeze or lose identity. Existing explicit monitor-based tracking does not scale, while implicit inference from generative priors fails under prolonged occlusions. The key insight is to decouple semantic motion planning from pixel generation, using an LLM to generate 3D trajectories as control signals, thereby ensuring continuous independent motion and strict appearance consistency even after long out-of-view intervals.

## 核心方法 / Core Method

### 中文概述
- 整体框架：基于预训练 LingBot-World-Base 模型，构造一个由多模态条件引导的因果自回归生成系统，将视频生成重新定义为受控世界模拟。
- 数据管线：在游戏平台上生成 15 秒带精确相机参数的视频，利用 SAM3 提取 2D 边界框轨迹；为每个训练片段构建空间位置条件视频（彩色掩码编码实体身份轨迹）和外观条件视频（从历史帧中检索同对象区域，通过时间丢弃机制稀疏注入 RGB 特征，仅作为身份锚点）；并采用双视角（静态 FOV 重叠 + 动态对象贪心选择）检索上下文记忆帧。
- 模型设计：
  - **位置条件 B** 和 **外观条件 A** 通过 3D VAE 编码后与带噪潜变量通道拼接，外观通道权重从首帧处理器初始化以转移 RGB 身份，位置通道零初始化作为残差学习轨迹驱动生成。
  - **时间丢弃机制**：针对每个实体，仅在进入视野的前 16 帧密集保留外观参考，之后每 6 帧采样一帧，强制模型依靠轨迹和文本合成自然运动，防止外观条件导致滑动伪影。
  - **上下文集成**：将检索到的记忆帧（含对应的位置‑外观条件）序列拼接到当前生成片段前，通过大幅偏移的 RoPE 和不对称注意力掩码将上下文作为干净参考，训练时以 30% 概率随机丢弃上下文以支持首段自生成。
  - **相机注入**：利用 Plücker 坐标编码相对于当前生成块首帧的相对位姿，通过卷积提取多级运动嵌入注入 DiT 自适应归一化层。
  - **空间感知文本控制**：基于 GLIGEN 的空间加权交叉注意力，将实体特定 prompt 限制在其 2D 边界框区域内，避免语义泄漏。
- 推理流程：使用 Gemini 作为 LLM 编排器，根据用户指令规划全序列 3D 轨迹和相机运动，将视频切分为 5 秒片段逐块因果生成。

### English Summary
WorldDirector augments a video diffusion backbone with location and appearance conditioning channels derived from LLM-planned 3D trajectories projected to 2D. A temporal drop mechanism prevents overfitting to appearance anchors. Context memory frames are prepended with shifted RoPE and asymmetric attention, while camera motion is injected via Plücker embeddings and entity-specific text is grounded through spatial-aware cross-attention. The entire system generates long videos autoregressively in 5‑second chunks, maintaining dynamic object permanence.

## 启发性分析 / Insight Analysis

### 中文概述
- 论文并未提供系统的消融实验或深入的错误分析，正文主要集中于方法描述与定量对比。从方法设计中可以提炼几处关键设计动机：
  - **时间丢弃机制**：外观条件若全部密集注入，生成对象可能出现仅平移而无肢体运动的滑动伪影；通过强制稀疏化，迫使模型依赖轨迹和语义描述合成自然动态，外观条件仅作为身份锚——这一发现揭示了外观条件与运动生成之间的微妙权衡。
  - **上下文记忆的非对称注意力与 RoPE 偏移**：为防止带噪潜变量污染高保真历史帧，上下文仅自注意力且频率空间隔离，这种显式隔离保证了记忆的纯洁性和生成质量，体现了记忆注入与当前生成之间需要严格界面的设计哲学。
  - **双视角上下文检索**：同时考虑静态场景的 FOV 覆盖和动态对象身份覆盖，并强制最小帧间隔，说明仅依靠静态场景记忆不足以支持动态对象重入，验证了动态记忆的特殊性。
- 未明确提及规模化行为或理论支撑，整体仍偏工程实践；但框架的解耦思想本身具有很强的泛化潜力，可视为将大语言模型的空间推理能力与视频生成模型结合的范例。

### English Summary
The paper lacks explicit ablation studies, but several design choices imply valuable insights: the temporal drop mechanism reveals that over-conditioning on appearance leads to sliding artifacts, and sparse injection forces the model to rely on trajectory and text for natural motion. The asymmetric attention and shifted RoPE for context isolation highlight the need for a clean separation between memory and generation. The dual-stream context retrieval confirms that static scene memory alone is insufficient for dynamic object re‑entry. No scaling or theoretical analysis is provided.

- **作者承认的局限**：依赖合成游戏数据引入领域差距，偶尔导致视觉保真度下降（如不自然步态、模糊面部），未来将引入真实世界数据集弥合差距。
- **未提及但值得注意的局限**：
  - 评估依赖人工设计的进出视野场景，缺乏标准化基准，定量指标虽有多元对比但缺少用户主观评价。
  - LLM 编排器的空间规划能力未进行灵敏度分析，不同 LLM 或 prompt 可能产生轨迹偏差，系统鲁棒性未验证。
  - 外观条件检索基于最小宽高比差异，可能无法处理大幅姿态或形变，对非刚性对象的泛化性存疑。
  - 计算效率未分析：多个条件视频编码、上下文记忆拼接及 LLM 编排均增加推理开销，实时交互性存疑。
- **未来方向**：扩展到真实视频数据、处理更复杂物理交互（如碰撞、遮挡）、减少对精确边界框轨迹的依赖，以及结合 3D 先验提升相机运动下的几何一致性。

The authors acknowledge the domain gap from synthetic game data causing occasional visual fidelity loss. Unmentioned limitations include lack of standardized benchmarks, LLM sensitivity, reliance on aspect ratio for appearance retrieval, and computational cost. Future work should address real‑world data, complex physics, and reduced dependency on perfect bounding box trajectories.

# OrbitQuant: Data-Agnostic Quantization for Image and Video Diffusion Transformers

**Authors**: Donghyun Lee, Jitesh Chavan, Duy Nguyen, Sam Huang, Liming Jiang, Priyadarshini Panda, Timo Mertens, Saurabh Shukla

**Link**: https://arxiv.org/abs/2607.02461

**Importance**: 高优先级 (93.65)
**Why selected**: 直接针对扩散Transformer的高效推理这一关键需求，提出了一种新颖的数据无关量化方法，在图像和视频生成模型上达到了SOTA。
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

通过在归一化旋转基中构建固定分布的量化码本，OrbitQuant 实现了完全无需校准数据的扩散Transformer权值-激活量化，首次将图像DiT的PTQ推进到W2A4可用质量。  
*OrbitQuant achieves calibration-free weight-activation quantization for diffusion transformers by leveraging a fixed-distribution codebook in a rotated basis, pushing image DiT PTQ to usable W2A4 for the first time.*

---

## 动机 / Motivation

### 中文概述
- **问题**：扩散Transformer (DiT) 在图像和视频生成中质量顶尖，但其多步采样和庞大参数量导致推理成本极高。后训练量化(PTQ)是自然解法，但DiT的激活分布随时间步、提示词、分类器自由引导(CFG)分支剧烈漂移，使得现有方法必须为每个新checkpoint或模态重新收集校准数据并重新拟合量化参数。
- **现有工作缺口**：LLM PTQ 可通过校准数据捕获稳定的激活统计，而DiT缺乏这种稳定性，迫使方法如SVDQuant、ViDiT-Q等依赖昂贵的逐模型校准。尚无一种真正数据无关(data-agnostic)、跨模态即插即用的权值-激活量化方案。
- **核心观察**：若将归一化的激活向量通过一个随机正交旋转，其各坐标会收敛到一个与输入无关的固定分布（如N(0,1/d)）。这启发我们可以用一个离线构建的固定码本替代实时校准，解决漂移问题。

### English Summary
DiT activations shift across timesteps and prompts, breaking the calibration assumption in existing PTQ. The key insight is that a random rotation maps normalized activations to a known, input-independent distribution, enabling a single fixed codebook to serve all scenarios without calibration data.

---

## 核心方法 / Core Method

### 中文概述
OrbitQuant 是一种校准自由的权值-激活量化框架，其核心思想是将量化操作转移到一个统一的、旋转后的、归一化的基中进行。

1. **整体架构**：选取一种高效的随机置换分块Hadamard旋转(RPBH) $\Pi_d$，对于每个输入维度 $d$，离线构建一个针对该维度下旋转坐标固定分布 $f_d$ 的Lloyd-Max最优标量码本，供所有权值行和所有激活tokens共享。
2. **权值离线量化**：对于每个线性层 $W$, 提前将其右乘 $\Pi_d^\top$ 得到 $W'$，再对每一行做单位化，用码本量化方向向量，并保留行范数在BF16中。
3. **激活在线量化**：推理时，先将输入激活 $x$ 右乘 $\Pi_d^\top$ 得到 $x'$，计算其范数，用同一码本量化单位向量，最后放缩回范数。由于 $W'x' = W\Pi_d^\top \Pi_d x = Wx$，层内计算无需反向旋转，仅在激活进入层时施加一次前向RPBH旋转。
4. **关键创新**：与 TurboQuant 等需要逆向旋转的KV-cache量化不同，OrbitQuant 利用线性层的计算不变性，将旋转吸收到权值中，使得量化和解量化在矩阵乘法中直接抵消。随机置换（均匀随机）而非可学习或校准置换，仍能保证旋转后坐标的边际分布保持良好量化特性，省去了所有校准开销。

### English Summary
OrbitQuant quantizes both weights and activations in a shared, rotated, normalized basis. An offline-constructed Lloyd-Max codebook, computed from the known post-rotation marginal $f_d$, replaces per-input range calibration. The rotation is folded into the weights, cancelling in the linear layer, leaving only one forward RPBH transformation at runtime, with the uniform random permutation sufficing to maintain quantization fidelity.

## 启发性分析 / Insight Analysis

### 中文概述
- **旋转带来的分布固定性**：论文的核心洞察在于，经过归一化和随机旋转后，激活坐标的分布极度集中且可精确解析（近似高斯），这为无校准码本设计提供了理论保证。消融分析（文中提及但未详述）可能验证了不同旋转结构（如块Hadamard vs 稠密Haar）对分布拟合的影响。
- **随机置换的充分性**：与传统方法（如DuQuant, PeRQ）需要校准数据来学习或排序置换不同，OrbitQuant 发现均匀随机置换足以在低位宽下保持坐标的良好行为，这大幅简化了设计并彻底移除了数据依赖。
- **跨模态迁移性**：由于完全数据无关，同一套量化配置（旋转和码本）可直接从图像DiT迁移到视频DiT，无需任何模态特定的调整，显示了极强的泛化能力，并在实验结果中得到了验证。
- **极低位宽下的鲜活表现**：在W2A4等极度低位宽下，其他方法崩溃为噪声，而OrbitQuant仍能生成可识别的图像，这说明分布匹配码本比传统的逐通道缩放/网格量化更能保留高熵结构。

### English Summary
The paper's key insights are (i) the theoretical guarantee of a fixed post-rotation distribution enables a data-free optimal codebook; (ii) a uniform random permutation, rather than learned ordering, suffices for low-bit quantization; (iii) the method transfers seamlessly across modalities; and (iv) distributional codebooks maintain signal in extreme low-bit regimes where conventional methods fail.

## 局限性与展望 / Limitations & Future Work

### 中文概述
- **文中承认的局限**：提取的片段未包含明确的“局限性”陈述，但从方法设定可推断：依赖固定的Lloyd-Max码本和随机旋转，可能对于某些极端非高斯层的适应不够精细；AdaLN调制投影仍需使用简单的RTN，未纳入统一框架。
- **未提及但需注意的局限**：
   - RPBH的前向旋转虽比稠密旋转快，但仍引入了额外的在线计算开销，在极低延迟场景下可能成为瓶颈。
   - 方法当前仅验证于特定DiT架构（FLUX, Wan, CogVideoX），对于其他基于Transformer的扩散模型（如PixArt, Sora类）的泛化性待检验。
   - 理论上，随机置换的“均匀随机”虽避免了校准，但可能在某些层产生不理想的块内方差聚集，导致块内量化误差增加。
- **未来方向**：可探索自适应块大小、与低秩分解结合、支持动态激活位宽、扩展到更极端的W2A2/A3设置，以及针对视频的长时一致性的专门优化。

### English Summary
Limitations include the extra online rotation overhead, untested generalizability to all DiT variants, and the potential suboptimality of a uniform random permutation in some layers. Future work may involve adaptive block sizing, fusion with low-rank methods, and heavier compression levels.

## 个人思考 / Personal Takeaways

- OrbitQuant 将“数据无关”的追求做到了一个新的高度，其思想本质是：**通过几何变换将动态分布问题转化为静态码本问题**。这对其他时序变化剧烈的生成模型（如语音、音乐扩散模型）有极强的启发性。
- 值得深挖的一点是：随机置换的“足够性”是否具有深层理论支持？文中给出的概率保证非常吸引人，若能与其他保范变换（如DCT、learned transforms）建立更系统的比较，将进一步提升理论深度。
- 从实用角度看，无需校准的即插即用量化对于开源社区快速部署新模型极具价值，可直接作为Diffusers等框架的默认PTQ方案集成。
- 后续研究可以考虑将这种分布码本思路与激活感知的少量校准结合（如仅用十张图校准码本偏置），在保持数据极低依赖的同时进一步压缩精度损失，或探索在W2A2下结合稀疏化的可能性。

## 动机 / Motivation

### 中文概述
- **核心问题**：多模态大模型（MLLM）在真实部署中需持续适应新任务/新领域，但反复微调或联合重训极不现实；现有持续适应方法（参数高效微调、专家路由、回放）会累积适配状态，难以在固定内存预算下维持历史能力且不扰乱预训练的跨模态接口。
- **研究空白**：现有管线无论参数更新还是回放，都与严格固定内存的部署需求冲突；CLIP 式持续学习方法虽关注保留零样本能力，但无法直接迁移到自回归 MLLM，因为生成受逐层注意力和长程缓存交互支配。
- **核心洞见**：若将适配状态完全外部化为与原注意力机制兼容的紧凑 KV 记忆，并冻结骨干参数，则持续适应可以转化为一个预算约束下在线诱导集选择问题，从而显式地平衡稳定性与可塑性。

### English Summary
The paper addresses the challenge of continual adaptation of MLLMs under a strict, fixed memory budget. Existing methods (parameter updates, MoE routing, replay) inherently accumulate state and can perturb the pretrained cross-modal interface. The key insight is to freeze the backbone and externalize task knowledge as compact, attention-compatible KV memories. This reframes the problem as budgeted online inducing-set selection, decoupling adaptation from parameter changes and enabling full memory footprint control.

## 核心方法 / Core Method

### 中文概述
- **整体框架**：冻结 MLLM 全部参数，为每个训练前缀提取一条记忆条目：一个冻结的归一化检索键（末层池化输出），以及逐层压缩的键-值负载（通过分段平均池化）。在严格内存预算 B 下，通过双层优化选择紧凑的诱导集；推理时，根据查询键检索并加权记忆条目，将其负载拼接注入掩码自注意力缓存的额外令牌。
- **关键机制**：
  1. **冻结键与 KV 负载提取**：检索键由末层隐藏状态的均值池化再归一化得到（单位范数，便于余弦相似度检索）；每层对前缀的 K、V 张量进行等段平均压缩至固定长度 m，形成独立于任务维度的负载对。
  2. **检索加权与注意注入**：学习轻量校准参数 ϕ（温度 τ、逐层值门控 λℓ）。检索权重通过 softmax 归一化余弦相似度得到；记忆 KV 负载以加权拼接方式与原生键值组合，值部分受 λ 门控缩放，其余计算遵循标准因果掩码注意力。
  3. **双层诱导集选择**：
     - **内层**：给定选择权重 w，在训练集上最小化负对数似然加 ℓ₂ 正则，得到一个适配当前任务的校准器 ϕ⋆(w)。
     - **外层**：在预算 w ∈ W 下，同时优化当前任务似然、历史锚点保留（通过小规模锚点集 A<t）和光谱覆盖正则 Ωspec(w)（基于投影键的加权协方差 log-det 项，惩罚低秩冗余键）。
     - 最终取 w 的 Top-B 条目作为记忆 Mt，并固定用于后续任务。
- **与最相关工作的区别**：完全冻结骨干，记忆直接以 KV 负载注入注意力，而非依赖文本标记或适配器参数；将记忆更新形式化为在线诱导集选择，同时显式优化多样性，这不同于传统检索增强仅优化查询时的证据排序。

### English Summary
InduceKV freezes all backbone parameters and stores each training prefix as a memory entry: a normalized retrieval key (from final-layer pooling) and compressed layerwise KV payloads (via segment-mean pooling). At inference, a learned calibration (temperature and per-layer value gate) produces retrieval weights, and the weighted payloads are concatenated and injected into the masked self-attention cache. Under a fixed budget, memory is updated by bilevel optimization: the inner level fits calibration ϕ on the current task, and the outer level selects entries to jointly maximize current likelihood, retain anchor performance, and promote spectral coverage via log-det of the weighted key covariance. The final Top-B entries become the new memory. This framework reframes continual adaptation as online inducing-set selection without any gradient updates to the backbone.

## 个人思考 / Personal Takeaways

- 将持续适应完全解耦为外部 KV 记忆是一个优雅的设计，既简化了部署更新流程（无需改动骨干），又通过注入注意力提供了比文本检索更直接的干预。这为固定内存的多模态持续学习提供了新范式，值得作为 benchmark 与现有参数更新方法比较。
- 双层优化同时考虑当前似然、历史保留和多样性的思路值得借鉴，log-det 正则提供了一种可微的多样性控制手段，可能被用于其他 memory-augmented 或 coreset 选择场景。
- 然而，冻结骨干的假设在实践中可能过于严格：某些新任务可能真的需要调整底层特征，完全依赖冻结 KV 可能无法追平同时微调少量参数的方案。未来若能研究“近乎冻结”的策略，比如只训练极少数层或轻量门控，同时保持记忆预算固定，会是很有价值的折中。
- 关于推理开销，虽然论文声明以提示级检索为 baseline 有优势，但与无额外前缀传播的 PEFT 相比，延迟是否可接受仍需实验验证。也可考虑缓存检索键或使用快速近似，值得进一步探索。
- 整体来看，方法理论扎实，思路清晰。如果能补全消融实验和详细数据集结果（原文完整版应包含），可成为本领域一个强有力的 baseline，也值得复现和推广至其它模态（如纯文本长文档持续学习）。
