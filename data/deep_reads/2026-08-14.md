# Alaya-EVOKE: From Linear-Scaling Supervision to Endless World

**Authors**: Yuanyang Yin, Gongxuan Wang, Yifan Zhan, Chuanhao Li, Kaipeng Zhang, Feng Zhao

## 一句话总结 / One-liner

Evoke 通过将持久世界状态外部化到 camera-indexed world state bank、并重新设计教师模型以提供 30 秒长时程监督，蒸馏出三步、无 CFG 的交互式世界模型，在单张 H200 上以 2.11 秒生成 1.5 秒 chunk，实现有界成本下的开放式持续生成。

One English sentence: Evoke externalizes persistent world state into a camera-indexed world state bank and redesigns the teacher for long-horizon supervision, distilling a three-step CFG-free interactive world model that generates 1.5 s chunks in 2.11 s on a single H200 with bounded cost.

---

## 动机 / Motivation

### 中文概述

- **要解决的问题**：交互式世界模型必须同时满足三个需求：持久记忆、低延迟交互响应、以及从秒级到分钟/小时级的长时程生成。现有系统很难同时做到。
- **核心冲突**：如果在 denoiser 的 context frames 或 key-value cache 中保留历史，每个去噪步骤的成本会随时间增长；如果用 windowing 或 cache eviction 控制成本，就会丢失信息。低延迟通常依赖 few-step distillation，但 student 的能力受 teacher 的监督时域和 conditioning 能力限制。
- **关键观察**：持久状态和交互生成不必都由部署的 denoiser 承载。Evoke 将它们解耦：持久空间状态放到外部 world state bank，teacher 则被显式设计为能提供长时程、动态 conditioning 的监督源。
- **进一步细化的问题**：不同失败模式出现的时间尺度不同。degradation drift（曝光、饱和度、纹理退化）在短窗口内即可检测；而 content drift（场景身份、物体外观、布局逐渐变化）在每个局部窗口都看似合理，只有比较远距离时刻才能暴露。因此 supervision horizon 应被视为 teacher 侧的核心设计变量，而不只是加速手段。
- **为什么重要**：这使世界模型可以支持开放、连续演化的交互生成，而不是在 session 长度与记忆保留之间做折中。

### English Summary

The paper targets the conflict between persistent memory, low-latency interaction, and long-horizon generation in interactive world models. Existing approaches either grow denoiser context/KV cache cost over time or discard information via windowing/eviction, while few-step students are limited by short-horizon teacher supervision. The key insight is to decouple persistent state from the denoiser, externalizing it into geometric memory, and to treat supervision horizon and conditioning schedule as first-class teacher-side design variables.

## 核心方法 / Core Method

### 中文概述

- **整体框架：有界循环生成**。Evoke 把长时程生成形式化为对固定形状 chunk 的反复调用。每个 chunk \(x_k\) 含 \(F=9\) 个 latent frames，对应 36 个 pixel frames，即 24 fps 下的 1.5 秒。每一步输入 camera trajectory \(P_k\)、当前 text condition \(c_k\)、有界局部历史 \(h_k\)，并从外部世界状态读取相关几何信息。
- **外部世界状态库 World State Bank**：
  - 以 camera pose 为索引，保存场景几何信息。
  - 每个 step 先执行 `Read`：从当前 viewpoint 查询并 render 之前观测到的、重新进入 camera frustum 的表面，将其作为 pixel-space conditioning 注入生成器。
  - 生成后将新观测通过 `Write` 提升为场景几何，写回状态库。
  - 状态库有显式 read/write/eviction，并保持有界；当前实现保留有限时间窗口的几何，因此不是无限记忆，但在保留范围内提供 constant-cost recall。
- **Teacher 重新设计**：
  - 使用 chunk-wise sparse attention：每个 chunk 访问有界局部上下文、少量检索到的远处帧、以及 linear-attention global state。
  - 注意力成本从随序列长度二次增长降为线性增长，使 30 秒级监督可行。
  - 同一 chunk 结构允许每个 chunk 有独立 text condition，使单次 rollout 中可表示中途 prompt 变化和事件控制。
- **Distillation 到三步 student**：
  - 在 self-forced rollouts 下使用 30 秒 full-window distribution-matching objective，让 student 基于自身生成历史进行训练。
  - 蒸馏目标是三步、无 classifier-free guidance (CFG) 的 student。
  - Student 在 coarse-to-fine 的最粗层级注入渲染后的世界状态，同时接受短历史与当前 text condition。
- **与相关工作的区别**：
  - 相比 geometry-based conditioning 的先前工作，Evoke 强调把世界状态放进显式外部库，并有 bounded read/write/eviction，而不是仅做短程 warp 或 denoiser 内检索。
  - 相比把蒸馏当作单纯加速的工作，Evoke 把 teacher 本身作为设计变量：重点改变 supervision horizon 和 conditioning schedule。
  - 循环中复用相同的局部 positional layout，每个 chunk 不扩展位置编码范围；持久状态通过 camera pose 而不是时间位置访问，避免长时间生成超出训练位置范围。

### English Summary

Evoke is a bounded recurrent pipeline over 1.5 s chunks. Persistent scene geometry is stored in an external camera-indexed world state bank, rendered from the current viewpoint, and injected into the generator as pixel-space conditioning. The teacher uses chunk-wise sparse attention with linear-attention global state and per-chunk text conditioning, enabling efficient 30-second supervision. A distribution-matching objective under self-forced rollouts distills both long-range consistency and mid-session conditioning into a three-step CFG-free student.

## 启发性分析 / Insight Analysis

### 中文概述

- **对不同 drift 类型的区分是最重要的理论洞察**：
  - **Degradation drift** 改变局部统计量，可在短窗口内检测；现有 long-video objectives 通过强化局部稳定性可以改善它，但可能以牺牲 temporal dynamics/diversity 为代价。
  - **Content drift** 中，每个局部窗口都单独看起来合理，只有比较远距离时刻才暴露不一致。单纯增强局部稳定性不能解决它；需要延长 supervision horizon。
- **Supervision horizon 决定学习信号**：
  - 在 self-forced rollouts 下，student 用自己生成的历史作为条件，因此早期误差会扰动后续去噪的 conditioning distribution。
  - 较短的 supervision window 只捕捉到退化结果，而看不到产生这些结果的更早扰动；延长 horizon 扩大了 student 被监督的 rollout 扰动分布，并暴露长程不一致。
- **两个反直觉/容易混淆的点**：
  - 并不是所有长程不一致都应该通过更长监督解决。spatial revisit inconsistency（相机回到之前看过的表面时状态已经产生过）应交给外部几何记忆，而不是 longer supervision；temporal content drift 才主要靠长时程监督。
  - 所需的 supervision horizon 不必随最终 session 时长线性扩展。目标是让 recurrent dynamics 在正常生成中稳定，而不需要从任意损坏历史中恢复。
- **有界 recurrence 只是必要条件，不保证长期一致性**：它防止了逐 step 成本增长，但一致性来自 teacher 的 long-horizon supervision 和外部状态库的结合。
- **关于实验分析的可获得性**：提取文本中实验部分被截断，缺少实际 ablation 数值和误差分析。文中明确计划在 Section 4.2 检验 supervision horizon 是否饱和、以及 conditioning granularity 对 mid-session responsiveness 的影响，但具体数据未出现在本次提取内容中。小时级稳定性（Fig. 4）显示颜色保持平坦、scene identity cosine 达到 0.523、opening-window shift 远低于无关场景漂移，但作者明确标注这是 `n=1` 的稳定性声明，而非统计推断。

### English Summary

The key insight is the distinction between degradation drift, visible in short windows, and content drift, which only becomes apparent across distant moments. Extending the supervision horizon exposes content drift and broadens the rollout perturbation distribution under self-forced training, but not all consistency problems should be solved by longer supervision: spatial revisit consistency is handled by external geometric memory. The extracted text lacks detailed ablation numbers and statistical evidence, so quantitative insight analysis is limited.

## 局限性与展望 / Limitations & Future Work

### 中文概述

- **作者承认的局限**：
  - 当前 geometric world state 主要保留粗粒度场景结构，物体身份、外观和局部细节的细粒度一致性仍然有限。
  - 目前建模的主要是静态几何；动态状态，如物体运动、状态转换及其长期演化，尚未被显式表示。
  - 推理速度仍不够真正的 real-time interaction，需要更高压缩的视频 VAE、更高效的 few-step generator 和更低成本的 geometric conditioning。
- **未明确提及但值得注意的局限**：
  - world state bank 当前保留有限时间窗口的几何，并非对每个访问位置的无限记忆；长时间离开后重返旧区域可能无法恢复。
  - 外部几何记忆依赖 camera pose、深度/几何估计和 rendering，误差可能在长时间 rollouts 中累积。
  - 对动态物体、遮挡关系、光照变化和非刚性对象的持久一致性问题仍不明确。
  - 长 session 的定量评估仍偏弱：小时级结果是 `n=1`，缺少大规模 long-session benchmark。
- **未来方向**：
  - 引入 object-level 或 semantic world representation，以增强长期身份一致性。
  - 显式建模动态世界状态，支持连续更新。
  - 通过视频 VAE 压缩、生成器加速和轻量几何 conditioning 实现真正的实时交互。

### English Summary

Author-acknowledged limitations include coarse geometry, weak fine-grained object identity, lack of dynamic state modeling, and insufficient inference speed for true real-time interaction. Additional concerns include the finite temporal window of the world state bank, potential error accumulation in geometry estimation/rendering, and weak statistical evidence for long-session stability. Future directions include object/semantic world representations, dynamic state models, and further inference acceleration.

## 个人思考 / Personal Takeaways

- **架构解耦是核心贡献**：把“世界状态”从 denoiser 中彻底移出，使其成为有界 recurrent process 的外部模块。这种 denoiser 无状态 + external memory 的思路可以直接迁移到其他 autoregressive generation、world model 或 embodied simulation 系统。
- **Teacher 不应只是加速来源，而是课程设计者**：Evoke 明确把 supervision horizon 和 conditioning schedule 当作 teacher 侧设计变量。这说明 few-step distillation 的上限不取决于 student 结构，而取决于 teacher 监督中表达了哪些长程、动态能力。后续做蒸馏的同学可以借鉴：先定义 teacher 需要暴露的失败模式，再设计训练窗口和 conditioning。
- **Drift taxonomy 对长视频评估很有用**：将 drift 分为 degradation drift 与 content drift，并指出“每个局部窗口都合理”不等于“长程一致”。这提示评测 long video/world model 时不能只看短窗口统计，还需要设计专门的长程身份、布局和场景一致性指标。
- **Positional layout 复用是一个实用技巧**：通过每 chunk 复用相同局部位置编码、用 camera pose 访问外部状态，避免长时间生成的位置编码外推问题。这比不断扩展 RoPE 范围或强制训练更长位置更轻量，适合 streaming/recurrent 生成。
- **交互原语 “evocation” 值得转化为评测协议**：定时 prompt 切换、在保持锚定场景结构的同时引入/移除物体，为 world model 的响应性与一致性提供了一个直观、可定量的评测方式。
- **仍然存在的机会**：外部记忆目前是静态几何窗口，组合 object-centric memory、dynamic state、learned eviction/retrieval 可能成为下一步突破点；同时长 session 的严格统计评估和多基线对比仍需补充。

# V-RAE: Rethinking Video Latent Spaces for Generation

**Authors**: Minghui Guo, Shengqiong Wu, Hao Fei
**Venue**: arXiv
**Link**: https://arxiv.org/abs/2608.13556
**PDF**: https://arxiv.org/pdf/2608.13556
**Importance**: 高优先级 (96.2)
**Why selected**: Directly advances the priority subtopic of continuous visual tokenizers/representation autoencoders for video generation, with strong empirical gains and a new diagnostic metric. Signals: continuous visual tokenizer, representation autoencoder, video generation, world model, flow matching
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

V-RAE 直接在冻结视觉基础模型表征之上构建紧凑的视频生成潜空间，用轻量时序池化保留语义结构，并用时空 Transformer 解码器重建连续运动，在重建、语义保真和类别条件生成上超过大规模预训练视频 VAE。

V-RAE builds compact generative latents on frozen vision foundation model features via lightweight temporal pooling and a spatiotemporal decoder, outperforming large-scale video VAEs in reconstruction, semantic retention, and class-conditional generation.

---

## 动机 / Motivation

### 中文概述
- **解决的问题**：现有视频生成大多在视频自编码器定义的潜空间中进行，但这些潜空间主要按像素级重建目标优化，高层语义组织较弱；而“重建最优”的潜空间未必适合生成建模。
- **为什么重要**：潜空间结构直接决定生成模型的学习难度和生成质量上限；视频生成还需要同时建模外观、运动和长程时序依赖，因此潜空间质量尤为关键。
- **现有工作缺口**：已有方法多把语义特征作为自编码器或生成器的辅助监督信号，而不是直接把语义表征作为生成潜空间；图像领域的 RAE/RAEv2 已尝试使用冻结表征空间，但能否扩展到视频仍未被充分探索。
- **关键观察/出发点**：将冻结视觉基础模型特征作为视频生成潜空间存在三个新挑战：表征特征时序密集、压缩不足；压缩后必须保持时序一致性；时序压缩还要保留编码器继承的语义结构。

### English Summary
Existing video autoencoders are optimized mainly for pixel-level reconstruction, yielding latents with weak semantic organization that may be suboptimal for generative modeling. While image-based RAE methods show frozen semantic features can serve directly as generative latents, extending this to video is challenging because of temporal density, the need for temporal coherence, and the requirement to preserve semantic structure under temporal compression.

---

## 核心方法 / Core Method

### 中文概述
- **整体框架**：V-RAE 由三部分组成：冻结的视觉表征编码器、可学习的轻量时序池化模块、以及时空 Transformer 视频解码器；只有后两者被训练。
- **冻结编码器**：支持两类编码器。图像预训练编码器 DINOv3、SigLIP2、EUPE 逐帧编码，再沿时序组织空间特征；视频原生编码器 V-JEPA 2.1-L 直接输出时空特征。此设计统一接入图像型与视频型表征。
- **时序池化**：编码器输出 \(F \in \mathbb{R}^{T_E \times C \times h \times w}\)，时序池化把特征按长度 \(r_P\) 的不重叠窗口压缩为单个 latent feature map，采用 temporal attention pooling；总时序压缩率 \(r_{all} = r_E \cdot r_P\)。这既降低了 DiT 训练/推理成本，也保留了语义结构。
- **解码器**：采用带 3D RoPE 的时空 Transformer，配合 multi-frame unpatchify，将每个潜时序步映射到多个连续帧，以适应不同编码器的有效时序压缩率，并从压缩特征重建时序连贯的视频运动。
- **与相关工作的差异**：与像素重建导向的 VAE 不同，V-RAE 直接把冻结语义表征作为潜空间；与“语义对齐作为辅助损失”的方法不同，V-RAE 把语义特征本身作为生成潜空间。
- **说明**：所选提取文本未包含第 2.2 节 V-RAE Learning Objective 的完整损失函数公式，因此无法在此详细说明具体损失项。

### English Summary
V-RAE uses a frozen vision encoder, applies learnable temporal attention pooling to compress dense features while preserving semantic structure, and trains a spatiotemporal Transformer decoder with 3D RoPE and multi-frame unpatchify to reconstruct coherent video. Unlike prior methods that use semantics only as auxiliary supervision, V-RAE directly adopts frozen semantic features as the generative latent space.

---

## 启发性分析 / Insight Analysis

### 中文概述
- **反直觉发现：重建好 ≠ 生成好**。rFVD 和 gFVD 给出的自编码器排序差异明显，在 UCF101 和 K600 上的 Pearson 相关分别只有 0.200 和 0.473；高质量像素重建并不自动意味着潜空间适合生成。
- **提出 tFVD 作为更可靠的生成适用性诊断**。tFVD 通过解码潜空间插值轨迹来评估时序一致性，与下游 gFVD 的相关性显著更高：K600 上 0.919，UCF101 上 0.621。这说明时序一致性比纯重建质量更能预测生成效果。
- **语义保留与生成质量正相关**。V-RAE 的 latent 在语义 probing 上远强于传统 VAE latent，例如 DINOv3-L 变体在 UCF101 上 top-1 达到 89.13%，而最强 VAE baseline 仅 30.83%；跨编码器的结果显示更强的语义保留通常伴随更好的生成质量。
- **收敛速度提升**：在匹配训练设置下，V-RAE 的 K600 gFVD 收敛速度可比 VAE 潜空间快最多 6 倍，表明语义结构化的潜空间对生成模型更易学习。
- **局限性说明**：所选提取文本没有包含具体消融表的数值及深度错误分析；上述主要来自论文引言、摘要和结果讨论中的代表性数据。

### English Summary
A key finding is that reconstruction quality does not guarantee generation quality: rFVD and gFVD rankings are only weakly correlated. The proposed tFVD, which measures temporal coherence by decoding latent-space interpolations, correlates much more strongly with downstream generation quality. V-RAE latents also retain far more semantic information than VAE latents, and stronger semantic preservation generally coincides with better generation.

## 动机 / Motivation

### 中文概述
- 论文解决的核心问题是：交互式长时序世界模型中，条件信号与生成内容之间存在表征、时序结构和训练/推理行为不匹配，导致长 rollout 下视觉和几何一致性下降。
- 该工作针对的 gap 是上一版 AlayaWorld 的条件管线割裂：visual condition 常常被独立编码，temporal memory 未必与 causal VAE 的时序结构对齐，camera trajectory 又通过独立的 AdaLN 分支注入；这些条件与生成视频 latent 在 temporal structure、latent representation 或 train–inference 行为上可能存在偏差。
- 核心出发点是一条简单原则：conditioning signals should match the generated content as closely as possible in both latent representation and temporal structure。基于这一原则，报告保留原有 backbone 架构、chunk-wise autoregressive generation scheme 和训练数据不变，只重构条件信号的表示与整合方式。

### English Summary
The paper targets train–inference and representation mismatches in the previous AlayaWorld conditioning pipeline, where visual, temporal, and camera signals were processed through inconsistent pathways. Its key idea is to make all conditioning signals align with generated video latents in both latent space and temporal structure while keeping the backbone unchanged.

## 核心方法 / Core Method

### 中文概述
- 整体框架仍是 chunk-wise autoregressive generation：按 chunk 逐步生成视频，backbone 和训练数据不变。新版本主要替换了条件信号如何表示和注入。
- 两项大改动：
  1. 用 **streaming 3D point-cache renderer** 替代原先基于 DA3 的 depth-warping spatial memory。每生成一个 chunk 后，用 **ViGeo** 估计逐像素 3D geometry，把 per-pixel 3D points 注册到 persistent cache；下一 chunk 从计划 viewpoint 重新渲染 cache。相机轨迹通过 prefix displacements 上的 **pairwise-median ratio** 与 cache 做 scale alignment；intrinsics 每个 clip 用 least-squares fitting 估计一次并保持固定。
  2. 重新设计 conditioning pipeline，使 visual conditions 在同一个 **causal VAE latent space** 中编码，并与生成视频的时序统计量一致。
- 六项具体修改：
  1. **Motion-aware latent conditioning**：不再把 conditioning frame 当作孤立帧编码，而是构造 9-frame window（conditioning frame + 前 8 帧），用 causal VAE 编码整个窗口，取第二个 latent 作为 image condition；单个 conditioning frame 只保留为 decoder prefix。chunk-to-chunk handoff 复用相同的 9-frame 编码模式。
  2. **Causal encoding of streaming 3D spatial memory**：渲染出的 spatial condition 不再逐帧独立编码，而是 prepend 一个真实 prefix frame 后整段 causal 编码，再丢弃 prefix latent；无效渲染区域的 tokens 被直接移除而非 mask，以兼容 FlashAttention。
  3. **Pixel-aligned temporal memory**：temporal memory 从 6 个 latent 降到 4 个，并先在 pixel space 对齐窗口再做 VAE encoding；N=4 时编码 25 帧得到恰好 4 个 causal latents，消除 off-by-one boundary latents。
  4. **Hard memory dropout**：过去把 memory tokens 置零但保留位置，现在直接移除 memory tokens、改变序列长度；推理第一步无 temporal memory，与训练中 memory-free 情况一致。
  5. **Unified VAE protocol across training and inference**：统一训练、autoregressive rollout 和评估中的 pixel–latent 接口；chunk handoff 统一使用 anchor frame + 9-frame causal encoding window；decoding 支持 direct latent continuation 和 RGB decode–re-encode 路径。
  6. **Geometry-based camera control**：删除 camera AdaLN 分支。计划 camera trajectory 决定 3D point cache 的重渲染 viewpoint，渲染得到的 spatial condition 经过 causal VAE 编码后提供 viewpoint 控制。文本仍控制 scene semantics，几何条件控制 viewpoint。
- 与相近工作的主要不同：相比前版 AlayaWorld，新版本不再依赖 depth-warping 和独立 camera 调制，而是用同一套 causal VAE 潜空间表达视觉、空间记忆和相机信息；相比其他 video world model 中常见的独立 image encoding 或 camera AdaLN，它强调条件与生成 latent 的结构一致。

### English Summary
The method keeps the chunk-wise autoregressive backbone but revises conditioning: a streaming 3D point cache replaces depth warping, and all visual/spatial/viewpoint conditions are encoded causally in the same VAE latent space with matched temporal statistics. Six concrete changes implement this principle, including motion-aware latent conditioning, causal spatial-memory encoding, pixel-aligned temporal memory, hard memory dropout, a unified VAE protocol, and camera control through re-rendered geometry instead of AdaLN.

## 个人思考 / Personal Takeaways

- 这篇技术报告的真正价值不在新架构，而在一个明确且可迁移的原则：**条件信号必须与生成内容在 latent representation 和 temporal structure 上对齐**。这个原则看起来简单，但在 autoregressive video/world model 中常常因 image condition 独立编码、memory 窗口不一致、camera 走 side channel 而被破坏，是 train–inference drift 的重要来源。
- 几个非常实用的工程做法值得借鉴：
  1. 用同一 **9-frame causal encoding window** 统一 image conditioning、chunk handoff 和 evaluation，减少阶段专用编码协议。
  2. **Hard memory dropout** 直接改变序列长度，而不是把 memory token 置零，避免模型“看到 memory 是否存在”的虚假线索。
  3. 删除 camera AdaLN，改用 geometry-rendered spatial condition 来控制 viewpoint，使相机控制与 scene geometry、parallax、visibility 耦合，可能更自然也更稳健。
  4. 在 pixel space 先对齐 temporal memory 窗口，消除 off-by-one boundary latents，属于低成本但高收益的细节修复。
- 批判性看：本文是 v1.1 技术报告，结果呈现更像 benchmark report 而非完整研究论文。缺少消融、显著性、效率与失败分析，难以判断六项修改各自价值；而且它在一个以 navigation 为主的 split 上强，是否能在物理交互、操作任务中保持同样优势仍不清楚。
- 后续研究可尝试的方向：
  - 对六项修改做系统消融，量化 latent 对齐、memory dropout 和 point-cache renderer 的独立贡献。
  - 把同样的对齐原则扩展到 action/text token 或机器人 world model 的 action conditioning。
  - 用 3D point cache 做显式 geometry-aware reward 或 collision-check，支撑物理交互任务。
  - 设计更严格的 train/inference distribution shift 度量，验证 condition-alignment 是否是长 rollout 一致性的可复用理论工具。
