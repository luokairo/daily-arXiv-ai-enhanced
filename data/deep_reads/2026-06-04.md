# Echo-Infinity: Learning Evolving Memory for Real-Time Infinite Video Generation

**Authors**: Yuxuan Bian, Zeyue Xue, Songchun Zhang, Shiyi Zhang, Weiyang Jin, Yaowei Li, Junhao Zhuang, Haoran Li, Jie Huang, Haoyang Huang, Nan Duan, Qiang Xu
**Venue**: arXiv

**PDF**: https://arxiv.org/pdf/2606.04527
**Importance**: 高优先级 (97.15)
**Why selected**: Directly advances continuous autoregressive video generation with a learnable memory mechanism, aligning with top priority subtopics and boost keywords. Signals: continuous language model, autoregressive video generation, video generation, world model, efficient inference
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

Echo-Infinity 提出可学习的演化记忆查询（Memory Queries）和统一相对 RoPE 配方，首次实现 24 小时实时无限视频生成，在任意长度历史上以恒定计算成本动态过滤、抽象和压缩，消除 KV 缓存膨胀与位置嵌入外推瓶颈。  
Echo-Infinity introduces learnable evolving memory queries that filter, abstract, and compress arbitrary-length history at constant cost, together with a unified relative RoPE recipe, enabling the first 24-hour real-time infinite video generation without memory growth or positional extrapolation.

---

## 动机 / Motivation

### 中文概述
自回归视频扩散变换器（DiT）在长期流式生成中面临两个根本瓶颈：  
1. **无界 KV 缓存**：历史帧的 key-value 缓存随视频长度线性增长，导致内存和计算不可控。  
2. **RoPE 外推与溢出**：时间轴上的旋转位置编码索引会超过预训练范围（如最大 20），导致质量骤降甚至数值溢出。  

现有工作采用三类被动策略：窗口截断（丢弃远历史）、手工规则的 KV 缓存管理（固定预算，忽略自回归累积误差）、或启发式压缩（依赖分离目标或固定压缩比）。这些方法均未端到端学习需要保留哪些历史信息。受人类记忆分层巩固（工作记忆→过滤、抽象、压缩→长时记忆）启发，本文提出：长期视频生成应该依赖一个紧凑的、可演化的状态，而非存储每一个过去 token。同时，RoPE 的外推问题在训练时即应解决，而非仅在推理时补救。

### English Summary
Long AR video generation suffers from unbounded KV cache growth and temporal RoPE index overflow. Existing handcrafted cache management and inference-time RoPE fixes lose historical information or cause train-test mismatch. Inspired by human memory consolidation, this work argues that a compact, evolving memory state learned end-to-end can replace per-token history storage, while a training-time relative RoPE schedule eliminates extrapolation completely.

---

## 核心方法 / Core Method

### 中文概述
Echo-Infinity 有两个核心组件：

1. **可学习的 Memory Queries**：  
   - 维护一组可训练 token（Memory Queries）作为长期记忆，与局部 KV 缓存和 sink 帧并存。  
   - 当过去帧从局部窗口移出时，Memory Queries 通过**交叉注意力**处理被移出的 KV 缓存，随后经过 **sigmoid 门控残差更新**，动态过滤无关信息、抽象并压缩历史。  
   - 更新后的 Memory Queries 与当前帧的 KV 缓存拼接，注入 DiT 的因果注意力计算，提供“历史回声”。  
   - 整个过程**计算量恒定**（与视频长度无关），压缩比完全由可学习机制决定，无需手工设定。

2. **统一相对 RoPE 配方（Unified Relative RoPE Recipe）**：  
   - 训练与推理统一采用相对 RoPE：将 sink 帧固定为 id 0，最新帧从 0 增长到预训练最大索引 f_max（如 20）后，所有更早帧的 id 向后旋转，确保所有活跃时间 id 始终落在训练分布内。  
   - 彻底消除训练-测试的 RoPE 外推差距，同时避免推理时的长度溢出。

与 MemFlow（基于检索的手工缓存）、Memorize-and-Generate（分离压缩与生成）等不同，Echo-Infinity 将记忆压缩过程端到端地集成在生成损失中，不改变 DiT 结构，属于即插即用的 KV 缓存增强。

### English Summary
Echo-Infinity replaces manual cache curation with trainable Memory Queries that read evicted KVs via cross-attention and update themselves through a gated residual, achieving constant-cost history compression. A unified relative RoPE schedule is applied during both training and inference to keep every temporal id within the pretrained range, removing any train-test mismatch and overflow risk.

## 启发性分析 / Insight Analysis

### 中文概述
论文在分析方面主要呈现以下几点：

- **记忆查询的泛化先验作用**：即便在推理时禁用 Memory Queries 更新，仅使用训练好的初始状态，也能提升短视频生成质量，说明它们学到了一种通用的生成先验，而不仅仅是对长历史的即时整合。
- **与竞争方法的定性对比**：图 1 展示了 Echo-Infinity 在 24 小时连续生成中保持一致性，而 LongLive 在 4.25 分钟即出现严重退化，叠加相对 RoPE 后依然因记忆受限而逐渐漂移；这表明可学习记忆比被动截断或手工规则更稳健。
- **常数开销的可扩展性**：在 18.5 FPS 吞吐下，相比无记忆基线仅增加 10.6% 的计算开销，同时支持 >130 万帧的实时 rollout，证明该记忆机制在工程上的可行性。
- **训练-测试 RoPE 一致性**：消融或者说比较中间接地强调，仅在推理时切换为相对 RoPE（如 LongLive*）仍不足以保持长程一致性，因为模型在训练时从未见过此类位置关系；必须将同一相对机制用于训练，这是之前工作忽略的关键点。

论文缺少定量的消融研究（如 Memory Queries 数量、交叉注意层数、压缩比的影响）和错误分析（哪些场景下记忆会失效），因此深入程度略显不足。

### English Summary
Key insights include: (1) the learned memory queries act as a generalizable generation prior even without online updating; (2) purely inference-time RoPE adaptation is insufficient—training-time alignment is essential; (3) constant-cost memory enables 24-hour real-time generation with only 10.6% overhead. However, the paper lacks detailed ablations or failure mode analysis.

## 局限性与展望 / Limitations & Future Work

### 中文概述
作者在文中未明确列出局限性。可观察到的局限包括：
- **只在单一预训练模型上验证**（Wan2.1-T2V-1.3B），未测试更强或不同架构的 DiT，限制了结论的普适性。
- **长视频训练数据有限**：仅用 60s 的单提示切换序列微调，可能过拟合特定分布，对于复杂叙事或多重大场景切换的泛化能力存疑。
- **Memory Queries 的容量固化**：查询数量在训练后固定，无法动态调整压缩粒度以适应不同上下文复杂度。
- **缺乏理论分析或解释性**：对记忆查询究竟学到了何种模式的稀疏或抽象表示，没有可视化或探针分析。
- **交互式场景未充分评估**：声称支持交互式视频生成，但实验仅覆盖单提示持续生成，未演示多轮交互或用户输入时的记忆鲁棒性。
- **实时性仅在最理想条件下展示**：18.5 FPS 在 H100 上达到，但实际部署中可能面临更严苛的延迟和内存约束。

未来可探索：自适应压缩比、记忆查询的可解释性、在多模型/多尺度下的泛化、与结构化世界模型融合、以及更丰富的交互式流生成评测。

### English Summary
Limitations include evaluation on only one DiT backbone, limited long-video training data, fixed memory capacity, lack of interpretability or theory, and no real interactive scenario testing. Future work could investigate adaptive compression, multi-model generalization, and richer user-interaction benchmarks.

## 个人思考 / Personal Takeaways

- **记忆演化的学习范式是长序列建模的关键**：Echo-Infinity 将记忆选择的权利交给梯度优化，而不是依靠人类设计的启发式规则，这种“记忆作为动态状态”的思想对各类自回归生成（文本、语音、视频）都有借鉴意义。未来可探索 Memory Queries 与线性注意力、状态空间模型的融合。
- **训练-测试一致的重要性再被证明**：只在推理时修改 RoPE 计算是不够的，必须与训练对齐。这一原则同样适用于其他位置编码（如 ALiBi、NoPE），提醒我们在设计长上下文外推方法时应优先考虑训练阶段的集成。
- **实用至极简的工程可行性**：仅 10.6% 的额外开销实现 24 小时流式生成，显示该记忆模块的轻量高效。这为视频基础模型的长期连续部署（如监控、自动驾驶世界模拟）提供了一个高性价比的蓝图。
- **缺少严格的消融与失败分析是一个明显的薄弱点**：如果补充不同 Memory Query 数量、压缩窗口、交叉注意深度等的梯度，以及对记忆漂移或灾难性遗忘的定量诊断，将极大增强说服力。后续研究可以在此基础上补全这些实验，探明其工作边界。
- **可扩展至交互式世界模型**：该记忆机制天然适合作为自回归世界模型的状态编码器，可以通过条件化外部动作输入，进一步展开成视频预测。结合强化学习，可能构建一个高效的长时程世界模拟器，值得深入挖掘。

# ChannelTok: Efficient Flexible-Length Vision Tokenization

**Authors**: Sukriti Paul, Arpit Bansal, Tom Goldstein

**PDF**: https://arxiv.org/pdf/2606.04461

Signals: continuous visual tokenizer, channel-wise tokenization, flexible-length tokens, efficient autoregressive image generation, CNN-Transformer hybrid
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

ChannelTok 提出一种通道级的灵活长度视觉 tokenizer，通过训练时随机尾部丢弃隐式地学习通道语义排序，以较低参数量和极快推理速度实现了可变 token 预算下的高质量重建与自回归生成。

ChannelTok introduces a channel-wise flexible-length visual tokenizer that learns a semantic channel ordering via stochastic tail-dropping, achieving high-quality reconstruction and autoregressive generation across variable token budgets with far fewer parameters and much faster inference than prior works.

---

## 动机 / Motivation

### 中文概述
- **解决的问题**：现有灵活长度视觉 tokenizer 为了获得高质量，普遍采用参数繁重的 ViT 骨干和慢速的多步生成式解码器（如整流流或 Transformer 解码），推理成本和模型尺寸极大，难以实际部署。
- **目标缺口**：需要一种轻量、高速、同时保持高重建质量的灵活长度 tokenization 方法，使其能真正适用于边缘设备和实时应用。
- **核心观察**：近期固定长度 tokenizer 的研究发现，潜在通道维度本身会自然地形成从粗到细的语义层次，无需显式排序约束。这一发现暗示通道维度是实施灵活 token 化的理想轴——可将每个通道视为一个视觉 token，并迫使早期通道学习粗粒度结构，后期通道补全细节。

### English Summary
Existing flexible-length tokenizers rely on heavy backbones and slow multi-step decoders, making them impractical for real-world deployment. The paper observed that latent channels in fixed-length tokenizers exhibit a natural coarse-to-fine hierarchy, and proposes to exploit this channel dimension as the token axis to build a lightweight and fast flexible-length tokenizer.

---

## 核心方法 / Core Method

### 中文概述
- **整体框架**：基于 VQGAN 的自编码器，但彻底改变 token 定义——将每个潜在通道切片视为一个独立的视觉 token（而非空间 patch）。编码器含 CNN 下采样和多个分辨率的自注意力模块，输出潜在表示 z ∈ R^{C×h×w}；解码器对称上采样重建。
- **核心机制**：**自适应通道掩码 (Adaptive Channel Masking)**。训练时，对每张图像：
  1. 以概率 p_mask 决定是否施加通道丢弃；
  2. 若施加，从 [t_min, t_max] 均匀采样保留比例 t，仅保留前 k = ⌈t·C⌋ 个通道（活动通道），尾部 C-k 个通道置零并停止梯度；
  3. 活动通道独立进行 Binary Spherical Quantization (BSQ)；
  4. 解码器仅利用活动通道重建图像。
  这种随机尾部丢弃相当于一种因果约束，迫使编码器将最重要的信息压缩到低索引通道，从而自然形成从粗到细的语义排序；推理时只需保留前 k 个通道即可获得不同压缩率下的完整图像。
- **与现有方法的区别**：现有灵活 token 化主要在空间维度操作，通过尾部 token 丢弃或嵌套编码实现多种压缩率，但需要显式排序损失或复杂训练策略。本方法直接利用通道维度，不引入额外参数，训练简单，且天然支持变长自回归生成（因为通道已按语义重要性排序，生成时可以截断后续通道仍得到完整图像）。

### English Summary
ChannelTok treats each latent channel as a token. During training, it randomly retains only the first k channels and masks the rest with stop-gradient, forcing the encoder to organize channels by importance. A standard VQGAN with BSQ and a simple CNN-Transformer backbone then reconstructs from only the active channels. This differs from spatial flexible tokenizers by exploiting the inherent channel hierarchy without explicit ordering losses.

## 启发性分析 / Insight Analysis

### 中文概述
- **消融揭示的关键行为**：
  - 随机丢弃概率 p_mask = 0.5 最优，过低的采样频率会让模型退化到无排序状态，过高则削弱高 token 预算下的重建质量。
  - 保留比例 t 的采样策略应为均匀采样 (Normal bias)；若偏向高 token 预算 (Bias High) 会降低低 token 时的质量，反之亦然。
  - 模型容量增大持续提升重建质量，尤其是低 token 预算下的 rFID 改善更显著。
- **通道语义转移实验**：交换两幅图像的前 t 个通道，当 t 较小（如 32）时，主要转移了光照、色彩等风格属性，主体物体保持；t 较大（64 以上）时，前景物体开始融合变形。这直观验证了早期通道编码全局结构、后期通道补充局部细节的层次性。
- **反直觉发现**：不加尾部丢弃的基线模型，其通道重建渐进图呈现无意义的随机波动，语义内容直至最后几个通道才涌现。而引入随机丢弃后，通道涌现出平滑且单调改善的重建质量曲线，说明这种排序不是模型结构天然具备的，而是训练时引入的因果压力所强制形成的。
- **自回归生成效率**：LlamaGen 生成的 FID 从 32 通道到 128 通道骤降（20.71 → 7.96），但 256 通道时仅略微改善至 7.85，表明早期 128 个通道已承载绝大部分语义信息，边际效益递减，这为变长生成提供了有力的效率依据。

### English Summary
Ablations show that balanced masking and uniform sampling of retention ratios are critical for robust ordering. Channel swapping experiments confirm a coarse-to-fine hierarchy. Notably, without tail-dropping, the baseline exhibits no ordering; the semantic hierarchy is induced solely by the causal masking objective. In autoregressive generation, most perceptual gains are achieved by the first 128 tokens, demonstrating diminishing returns and efficiency of early-channel semantics.

## 局限性与展望 / Limitations & Future Work

### 中文概述
- **作者未明确声明的局限**（但可从方法中推断）：
  1. 仅在 ImageNet 上验证，缺乏更多样场景（如视频、医学图像、高分辨率自然图像）的证据。
  2. 自回归生成实验限于 ImageNet-100 子集与较小的 GPT-L 模型，大规模生成质量和扩展性待检验。
  3. 通道维度固定为 512，对于极复杂或极高分辨率图像可能存在容量瓶颈。
  4. 推理时需要手动选择 k，没有内容自适应的动态预算分配机制。
- **未来方向**：
  - 扩展到视频 token 化或 3D 表示，利用时域或视角的通道层次。
  - 结合扩散解码头提升感知质量，或探索更大规模 AR 生成（如 >1B 参数）。
  - 设计一个轻量级预测器，依据图像复杂度动态输出最优 k，实现真正的内容感知压缩。
  - 进一步探究通道语义解耦，可能通过对比学习或感知损失加强不同通道间的语义独立性。

### English Summary
Limitations include ImageNet-only evaluation, small-scale autoregressive generation, and fixed channel counts. Future work involves extending to video/3D, larger AR models, and dynamic budget prediction. The lack of explicit semantic disentanglement in channels is also a point for improvement.

## 个人思考 / Personal Takeaways

- **核心亮点与实用性**：将 tokenization 从空间轴转移到通道轴是一个简洁而深刻的范式转换。它既保留了 VQGAN 高效的编码-解码流程，又通过简单的训练技巧（随机通道丢弃）获得了灵活长度能力，非常适合作为多模态大模型的图像表征模块，特别是在边缘设备或实时场景中。
- **方法论启示**：“因果压力塑造表示排序”的思路值得关注——仅通过随机截断并停止梯度，网络便能自发学习到可解释的层次结构。这一策略或许可以迁移到语音、文本等其他序列模态的变长表示学习中。
- **潜在研究拓展**：
  1. **与连续语言模型结合**：将通道 tokens 直接输入自回归语言模型，利用早期通道的高信息密度，在语言模型推理早期即可获得粗粒度的图像理解，逐步细化，实现计算与认知 latency 的灵活权衡。
  2. **渐进式传输与渲染**：对于图像/视频流式传输，可按重要性优先发送前若干通道，接收端即使仅收到少量通道也能快速呈现模糊的全局视图，然后逐渐清晰。
  3. **分析通道内容**：可视化每个通道独立解码后的图像（类似于特征可视化），可能会发现某些通道专司纹理、颜色、形状等属性，可据此设计可控生成或编辑工具。
- **需要注意的风险**：通道排序完全由尾部丢弃隐式习得，缺乏显式语义监督，可能导致通道间的功能重叠或缠结，在极致压缩率下可能丢失某些细节类别。后续可考虑加入通道重要性排序的正则化项（如使各通道解码结果的信息增量最大化）来获得更紧凑的表示。总之，该工作为高效视觉 token 化开辟了新的思路，值得跟进探索其在大模型时代的应用潜力。

## 动机 / Motivation

### 中文概述

- **要解决的问题**：视频 Diffusion Transformer 视觉质量虽好，但推理成本极高，难以落地实时应用。已有的蒸馏方案虽能加速，却对每一帧使用相同的去噪步数，忽略了视频序列在时间维度上的复杂度差异。
- **现有方法的缺口**：自回归视频扩散模型固定步数推断，导致简单帧（如低运动）浪费算力，复杂帧（快速运动、结构剧变）又细化不足。
- **核心观察与出发点**：视频帧天然存在难度不均——低运动帧仅需极少去噪即可生成，高动态帧则需要更多细化。若能每帧自适应分配步数，就能打破固定预算造成的速度‑质量妥协。

### English Summary

Existing distilled autoregressive video diffusion models use a fixed number of denoising steps per frame, ignoring that video frames vary in temporal complexity. This observation motivates DSA: predictable frames can be generated with fewer steps while challenging ones need more, breaking the uniformity waste.

---

## 核心方法 / Core Method

### 中文概述

DSA 的整体框架是一种在**分布匹配蒸馏（Distribution Matching Distillation, DMD）**框架下的自适应计算策略，专门面向因果（autoregressive）视频扩散 transformer。

- **框架与流程**：
  1. **联合训练**：在自回归生成器的训练过程中，插入一个轻量级**置信度头**（confidence head）。该头与去噪 transformer 共享主干特征，并被联合优化，预测当前帧去噪结果的可靠度（置信度分数）。
  2. **训练范式**：基于 Self Forcing [20] 的滚动 KV 缓存训练，但额外输入置信度分数进行条件去噪，目标是让学生分布匹配双向教师分布。
  3. **推理时动态分配**：对于每一帧，根据置信度头预测的分数决定去噪步数：当置信度超过阈值时提前终止（early termination），低置信度帧则继续额外细化。

- **与最相关工作的区别**：
  - 相比于 Self Forcing 等固定步数自回归蒸馏方法，DSA 首次在蒸馏中引入质量感知的置信度目标并用于在线步数决策。
  - 不同于基于缓存的加速（需要完整上下文注意力），DSA 只依赖因果注意力，天然适合流式生成；也不需要额外视频数据或人工启发式规则（no extra data, no heuristics）。
  - 架构改动极小：仅添加一个轻量置信度预测网络。

### English Summary

DSA jointly trains a lightweight confidence head with the causal DiT under distribution matching distillation. At inference, the confidence score dynamically terminates denoising early for simple frames or extends it for complex ones. No extra data or handcrafted heuristics are needed, and the architecture is minimally modified.

## 启发性分析 / Insight Analysis

### 中文概述

- **速度‑质量权衡的重定义**：从论文给出的速度‑质量曲线（VBench Total Score vs. FPS）可以看出，固定步数的减少虽然提升吞吐，但会明显损害质量；固定多步虽恢复质量，但 FPS 骤降。DSA 的动态分配找到一个明显的“甜点区”——在 83.95 VBench Total Score 的同时维持 22.01 FPS 的高吞吐，优于所有固定步数基线。这表明**非均匀计算分配可以同时逼近高质量与高速度**。
- **置信度信号的可靠性**：虽然没有显式消融置信度头设计，但通过能够自适应地区分需要不同步数的帧，间接证明联合训练出的置信度分数能够有效感知帧级去噪难度；简单帧提前终止并未显著降低整体生成质量。
- **长时生成的退化**：DSA 在长视频序列上表现下降（作者承认的时间漂移与累积误差），这是自回归模型的共性问题。动态分配步数并未解决误差传播的根本问题，反而可能因为早期帧提前终止导致更深层的误差放大，这是一个值得关注的隐患。
- **缺失的深入分析**：论文未提供不同阈值选择对 FPS‑质量的详细消融、置信度分数分布的统计、以及模块本身的计算开销分析。这些可能削弱了对方法有效性的深入理解。

### English Summary

The speed-quality trade-off demonstrates that adaptive allocation finds a superior operating point not achievable by fixed-step baselines. However, long-horizon generation still suffers from drift, and the paper lacks detailed ablation on confidence head behavior, threshold sensitivity, and overhead analysis.

## 局限性与展望 / Limitations & Future Work

### 中文概述

- **作者承认的局限**：长时视频生成中性能下降，时间漂移（temporal drift）和累积误差更明显，这与先前自回归扩散模型一致。
- **我注意到的未提及局限**：
  - 论文没有分析置信度网络本身的计算开销是否会影响实时性能（尽管称为“轻量级”，但缺乏具体 FLOPs 或延迟对比）。
  - 对置信度预测的校准性（如是否过分自信）没有定量评估，如果置信度误差大，自适应策略可能适得其反。
  - 仅做了蒸馏场景验证，对于非蒸馏（从头训练或微调）的 AR 模型是否有效未知。
  - VBench 总分虽能反映总体趋势，但缺乏对运动幅度、场景切换等帧级复杂度的直接控制实验，干扰因素较多。
- **未来方向**：论文末句指出“自适应计算是高效视频扩散的一个有前景方向”，可能的延伸包括：
   - 结合更精细的帧级或区块级动态分配；
   - 将置信度信号与缓存策略、token 削减结合；
   - 设计方法抑制长序列累积误差，例如加入回退机制或记忆增强。

### English Summary

Acknowledged: performance degrades in long-horizon generation due to drift. Unmentioned: overhead of confidence head, calibration of confidence scores, applicability beyond distillation, and lack of direct control experiments. Future work could explore finer-grained dynamic allocation and error containment for long sequences.

## 个人思考 / Personal Takeaways

- **核心价值**：DSA 在“蒸馏‑加速”这个拥挤的赛道中找到了一个简单但高效的切入点：动态算力分配。思想直观，实现简洁（仅加一个置信度头），非常适合工业界要求快速落地的场景。
- **可改进点**：
  - 置信度网络的优化可以更激进，例如用强化学习直接优化 FPS‑VBench 指标，而非依赖分布匹配间接学习。
  - 与现有自回归视频模型的 KV 缓存、推测解码（speculative decoding）等技术正交，组合起来可能有更大加速空间。
- **对自己研究的启示**：动态计算不仅适用于视频生成，对于任何序列生成任务（如文本、音频）都有迁移潜力；关键是如何获得一个无需额外标注的、能在线感知难度的信号，DSA 用分布匹配蒸馏提供了一种可行方案，可以借鉴到我的工作中。
- **风险**：长序列的漂移问题可能限制 DSA 在高质量长视频（如1分钟以上）生成的应用，但可通过后处理或循环一致性策略缓解。若无详细消融，复现时需谨慎设计阈值。
