## 一句话总结 / One-liner

FlowWAM 提出以光流作为统一的视频原生动作表示，构建双流扩散框架，使同一个预训练视频生成器能同时实现策略模式与世界模型模式，在机器人操作和世界建模基准上均显著超越现有方法。

## 动机 / Motivation

### 中文概述
- 世界动作模型（WAM）试图复用预训练视频生成器进行世界建模和动作预测，但面临核心矛盾：如何选择一种既能与视频生成器无缝对齐、又能携带足够运动信息以支持精确控制的动作表示。
- 现有方案存在明显缺口：
  - 数值动作（如关节角度、末端位姿）与视频生成器的数据分布根本不对齐，难以直接融入扩散模型。
  - 先前基于视觉的动作表示（如静态 masks、goal images）忽略了帧间的时序运动结构，无法充分利用视频生成器的时序建模能力。
- 关键观察：光流（optical flow）天然是一种与 RGB 视频格式一致、逐像素编码位移信息的表示，并且可以从无动作标签的原始视频中高效提取，这使其有望成为连接视频生成和控制任务的桥梁。

### English Summary
Existing World Action Models struggle to represent actions in a form that aligns with pretrained video generators while preserving sufficient motion cues. Numerical actions are mismatched, and prior visual representations overlook temporal structure. The key insight is that optical flow, being a video‑format dense displacement field extractable from unlabeled videos, can serve as a unified action representation to bridge this gap.

## 核心方法 / Core Method

### 中文概述
- FlowWAM 是一个双流扩散框架，核心思想是将 RGB 视频和光流视频作为两个并行模态，在一个共享的预训练视频生成器中进行联合建模。
- 整体流程：
  - 预训练阶段：利用大规模无动作标签视频数据集，抽取光流序列，与对应 RGB 帧一同训练一个双流视频扩散模型，使其学会 RGB 与光流的联合分布。
  - 策略模式（Policy Mode）：给定当前观察，模型生成未来的光流视频，再通过一个轻量解码器将光流映射为最终的低维控制动作。
  - 世界模型模式（World‑Model Mode）：给定当前观察和期望的光流序列（即目标动作），模型以该光流作为条件信号，生成未来 RGB 视频，实现从动作到视觉结果的预测。
- 与最相近工作的核心区别：不同于 Genie、UniSim 等仅用视频生成器做世界建模，或使用离散 token 或无动作的 image‑goal 控制，FlowWAM 以密集光流作为统一的动作“语言”，使同一个模型自然地执行两种功能，无需额外的模态转换器。

### English Summary
FlowWAM jointly models RGB and optical flow videos in a dual‑stream diffusion framework. In policy mode, it generates flow for action prediction; in world‑model mode, it uses target flow sequences to guide future video generation. The key design is treating flow as a shared, video‑native action representation, enabling seamless mode switching within a single pretrained generator.

### 中文概述

## 核心方法 / Core Method

### 中文概述
- **整体框架**：基于 Wan-1.3B 视频扩散 Transformer，构建三个组件，并从单人游戏到完整双人游戏课程训练。
  - **流式自回归生成器 (Streaming Autoregressive Generator)**：引入块因果注意力（block-causal attention）和滚动 KV 缓存（rolling KV cache），将逐帧生成转换为低延迟的实时流式输出，避免全帧重新计算历史。
  - **玩家关联模块 (Player Association)**：视觉接地方式，将不同玩家的键盘输入信号绑定到屏幕上的特定角色，解决多人指令混淆问题。
  - **键盘注入模块 (Keyboard Injection)**：采用局部因果掩码的门控注入机制，确保当前帧生成仅依赖过去及当前按键，符合实时交互的因果关系。
- **加速推理**：使用 DMD (Distribution Matching Distillation) 将扩散采样步数蒸馏为仅 4 步，并结合剪枝后的 VAE 解码器，在单张 NVIDIA RTX 5090 上以 512×384 分辨率稳定达到 30 FPS，覆盖一场完整比赛时长。
- **与现有工作区别**：不同于单玩家游戏引擎（如 GameNGen、DIAMOND）或预录制交互模拟，WanToFight 首次在生成模型中实现多玩家有状态对抗、实时格斗物理和长程一致性。

### English Summary
WanToFight augments a Wan-1.3B backbone with a streaming autoregressive generator using rolling KV cache, a player association module for binding inputs to characters, and a keyboard injection module with local causal masking. A 4-step DMD-distilled student and pruned VAE decoder achieve 30FPS real-time performance.

## 动机 / Motivation

### 中文概述
- 视觉语言模型（VLMs）处理大量视觉 token，导致显著的推理延迟和内存开销，这催生了对视觉 token 压缩的大量研究。
- 现有方法分为两类：training-free 策略依赖启发式度量，在高压缩比下性能下降严重；training-based 方法引入外部压缩模块，迫使 VLM 主干去适应，不仅需要昂贵的重训练，还会损害 VLM 原有的先验知识。
- 关键观察：有效的视觉 token 压缩依赖于强大的信息编码能力，而这种能力在预训练 VLM 中已经存在，但现有方法未能充分挖掘。

## 核心方法 / Core Method

### 中文概述

### English Summary
VisCo is a parameter-sharing autoencoder that directly uses the pretrained VLM as both the encoder and decoder. It compresses visual information into a small set of learned memory tokens and transfers hierarchical information from encoding to decoding. Unlike prior work, it introduces no external compression modules, keeping the VLM backbone intact and drastically reducing training cost.

## 个人思考 / Personal Takeaways

- 将预训练 VLM 自身转换为压缩器的思路极其简洁优雅，本质上是一种“无外部依赖的特征自蒸馏”。这为多模态模型轻量化指明了新方向：与其设计复杂的 Token 剪枝/合并策略，不如挖掘模型内部尚未被利用的信息编码通道。
- 即便在极端单 token 下仍保持稳定，说明 VLM 内部存在高度浓缩的视觉原语，这或许能反过来指导视觉编码器的预训练目标设计。
- 压缩后的记忆 token 能提升基模型性能这一现象非常值得深入：可能意味着模型在常规训练中存在表征冗余或信息瓶颈，压缩反而充当了正则化或重要特征放大的角色。这可以成为后续研究的一个有趣角度：从压缩视角反哺模型架构改进。
- 由于缺少全文实验细节，需谨慎对待性能声明的公平性与可复现性。若有机会，应验证其对基座模型的选择、微调数据规模及评估任务的敏感度。此外，将这种自压缩框架与目前流行的 Matryoshka-style 表示学习结合，或许能打造出弹性 token 压缩的实用方案。
