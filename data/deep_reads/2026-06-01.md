# Representation Forcing for Bottleneck-Free Unified Multimodal Models

**Authors**: Yuqing Wang, Zhijie Lin, Ceyuan Yang, Yang Zhao, Fei Xiao, Hao He, Qi Zhao, Zihan Ding, Fuyun Wang, Shuai Wang, Youliang Zhang, Haoqi Fan, Xihui Liu

**PDF**: https://arxiv.org/pdf/2605.31604
**Importance**: 高优先级 (97.15)
**Why selected**: Directly addresses bottleneck-free unified multimodal models with a novel representation forcing technique, aligning with top priority subtopics and boost keywords. Signals: unified multimodal model, bottleneck-free, representation forcing, autoregressive visual tokens, pixel-space diffusion
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

本文提出 Representation Forcing (RF)，让统一多模态模型直接预测自身理解编码器的视觉表征作为中间 token，从而在不依赖外部 VAE 的情况下实现像素空间生成，并同时提升理解与生成性能。
This work introduces Representation Forcing, which trains the unified model to predict its own understanding encoder’s representations as intermediate tokens, enabling pixel‑space generation without any pretrained VAE while improving both understanding and generation.

---

## 动机 / Motivation

### 中文概述

当前统一多模态模型（UMMs）虽在单一 Transformer 主干中融合感知与生成，但其图像生成路径仍依赖一个独立预训练且冻结的 VAE 作为生成隐空间。该依赖引入结构瓶颈：VAE 的隐空间仅为重建优化，损失压缩设置了生成质量的上限，且无法端到端适配模型整体目标。若直接去掉 VAE 改为像素空间生成，模型需从原始像素同时学习高层语义结构和底层纹理细节，导致生成质量明显劣于基于 VAE 的方法。关键观察是：UMM 的感知路径（理解编码器）已经能提取捕获高层结构（物体身份、布局等）的视觉表征，但在生成时缺少图像输入，模型必须自行“预测”这些表征。因此，作者提出让解码器主动预测来自自身编码器的视觉表征，以弥合这一结构鸿沟，实现无障碍的像素空间统一模型。

### English Summary

Existing unified multimodal models rely on a frozen, separately pretrained VAE for image generation, which imposes a structural bottleneck and cannot be optimized end‑to‑end. Naively removing it leads to a quality gap because the model must learn both high‑level structure and low‑level details from raw pixels. The key insight is that the model’s own understanding pathway already learns structural representations; by forcing the decoder to predict these representations during generation, the gap can be closed without external latent spaces.

## 核心方法 / Core Method

### 中文概述

Representation Forcing (RF) 的整体框架基于 Mix‑of‑Transformers (MoT) 骨干，所有 token 共享自注意力层，但分别路由到理解、表征预测和像素生成三个模态专用的 FFN 专家池。具体做法：
1. **表征来源**：使用与模型联合训练的理解编码器（DINOv3 ViT‑H+/16，通过 EMA 保持更新稳定）提取图像补丁级特征，经在线向量量化（codebook 大小 16,384，动量更新）离散化为视觉表征 token。离散化不但使 token 可用统一的下一 token 预测目标，还强制丢弃纹理细节，将高层结构与像素渲染解耦。
2. **生成流程**：训练时，序列组织为 [文本 token] → [表征 token] → [像素 patch token]。文本和表征 token 使用自回归的下一 token 预测损失（交叉熵），像素 patch 则采用双向扩散的 velocity loss（x‑prediction）。表征 token 由教师强制提供目标，同时保留在上下文中作为像素扩散的 structural scaffold。推理时，解码器仅从文本自动回归预测表征 token，再利用这些表征引导像素扩散，完全不使用外部 VAE。
3. **与已有工作的差异**：区别于 Chameleon、Janus 等依赖 VQVAE/VAE 的方法，RF 在单一 backbone 内端到端学习表征与生成；也不同于 REPA、RAE 等使用冻结预训练表征的方法，RF 的视觉表征来自模型自身联合训练的编码器且由解码器直接预测。

### English Summary

RF uses an MoT backbone. The decoder autoregressively predicts discrete visual representation tokens derived from online VQ of the jointly trained understanding encoder (EMA copy). These tokens remain in‑context to condition pixel‑space diffusion, all within the same transformer. No external VAE or frozen representation is needed. The model is trained with next‑token prediction for text and representation tokens and velocity loss for pixel patches.

## 启发性分析 / Insight Analysis

### 中文概述

消融实验揭示：
- RF 对像素空间生成至关重要：未加 RF 的 Pixel 模型质量远差于 VAE 基线，加上 RF 后即可匹配甚至略超。
- 离散化优于连续回归：离散量化因自然丢弃纹理细节，更好地将高层结构与像素渲染解耦，这使得扩散过程更专注于低层渲染，验证了作者关于“中间表征应保留结构、丢弃细节”的设计初衷。
- RF 不仅提升像素空间生成，对 VAE 设置也有辅助效果：在 VAE+RF 实验中，表征预测可以增强文本‑图像的语义对齐，但增益幅度小于像素空间。
- 反直觉发现：像素空间的 RF 模型在生成质量匹配 VAE 基线的同时，**理解能力普遍显著超越 VAE 变体**（6/8 基准更优），说明像素空间生成与统一多模态建模更兼容，原因可能是避免了 VAE 隐空间的语义扭曲。此外，RF 对通用视觉理解提升大，对文档/图表任务略有下降，可能因为文档任务依赖细粒度字符信息，而离散表征侧重高层语义。

以上分析总体表明：RF 通过对同一表征空间的双向使用（感知输出→生成目标），初步实现了感知与生成的紧密整合。

### English Summary

Ablations confirm RF is crucial for pixel‑space quality, with discrete representations outperforming continuous regression. Interestingly, the pixel‑space RF model not only matches VAE‑based generation but consistently beats the VAE variant on understanding benchmarks, suggesting pixel‑space generation is more compatible with unified modeling. RF improves general visual understanding while slightly reducing performance on document tasks, likely due to the high‑level semantic nature of the discrete tokens.

作者在讨论部分（由于截断不完整）隐含指出：模型初始化自预训练大语言模型（Qwen3‑A3B），这在一定程度上限制了从头端到端学习的主张；计算资源有限使得训练规模、数据多样性和消融实验的深度受到约束。未明确提及的局限可能包括：在线向量量化的 codebook 大小和更新策略可能对长尾数据覆盖不足；表征预测采用离散 token 在文档类任务上导致性能退化；当前只验证了文本到图像生成，尚未扩展到视频、语音等多模态。未来方向包括完全从随机初始化训练，扩展到视频等动态模态，以及探索更强的表征学习策略以同时保留高层语义与细节信息。

### English Summary

The model relies on a pretrained LLM initialization and limited training budget, which slightly tempers the “end‑to‑end from scratch” claim. Discrete tokens hurt document understanding. Future work could target training from scratch, extending to video/audio, and improving representation granularity for fine‑grained tasks.

## 个人思考 / Personal Takeaways

- RF 提供了一种极简而优雅的思路：将理解编码器本就学到的表征转化为生成的中间目标，不引入额外组件便弥合了像素空间生成的质量鸿沟，这对后续追求真正端到端统一模型的工作具有较强借鉴意义。
- 反直觉结论“像素空间生成更有利于统一多模态理解”值得深入挖掘：可能会改变社区对 VAE 隐空间的路径依赖，促使重新审视生成任务对理解能力的正反馈。
- 方法核心在于**在线量化 + EMA 稳定化**，这是一种利用更新缓慢的特征作为自监督目标的通用技巧，或许能推广到跨模态对齐、视频预测等任务。
- 潜在风险：离散表征虽然解耦了结构和纹理，但可能丢失部分稀疏细节，在需要像素级精度的任务（如分割、文档恢复）上可能不足，未来可尝试多尺度表征或混合粒度方案。
- 若未来能将 RF 推广到音视频生成与理解的统一，有望形成一个完全自包含的、从原始多模态信号中进行自监督学习的框架。

# Robust Dreamer: Deviation-Aware Latent Gaussian Memory for Action-Controlled AR Video Generation

**Authors**: Hanlin Chen, Jiaxin Wei, Xibin Song, Yifu Wang, Steve Wang, Hongdong Li, Pan Ji, Gim Hee Lee
**Venue**: arXiv
**Link**: https://arxiv.org/abs/2605.30855
**PDF**: https://arxiv.org/pdf/2605.30855
**Importance**: 高优先级 (97.15)
**Why selected**: Directly advances action-controlled video generation world models with a novel memory mechanism to solve long-horizon drift, a core user priority. Signals: world model, autoregressive video generation, latent Gaussian memory, deviation learning, 3D consistency
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

Robust Dreamer 通过在 3D Gaussian 原语上直接锚定并泼溅 RGB 生成过程继承的扩散潜变量，避免重复的 VAE 编解码退化，同时利用一步近似合成 rollout 潜变量偏移并注入训练历史记忆，实现了动作控制的长程自回归视频生成中视觉保真度与 3D 一致性的显著提升。
Robust Dreamer stores diffusion latents on 3D Gaussian primitives for direct splatting recall, avoiding repeated VAE degradation, and uses synthesized rollout deviations injected during training to dramatically improve long-horizon action-controlled video consistency.

---

## 动机 / Motivation

### 中文概述
动作控制的逐帧视频生成是实现交互式世界模拟极具前景的范式，但长自回归 rollout 中维持视觉保真度和 3D 一致性仍是重大挑战。现有基于 3D 记忆的方法普遍面临两大障碍：
1. **Latent–RGB Cycling**：生成潜变量被反复解码为 RGB 再重新编码，量化误差不断积累导致颜色漂移和结构退化（Fig.2a）。
2. **训练-推理 gap（error‑free hypothesis）**：训练时使用干净的 GT 记忆，而推理时记忆由不完美预测构建，干净记忆与污染记忆的分布偏移引发灾难性漂流（Fig.2b）。

这两点导致长程生成时场景逐步崩溃。本文从“如何设计 3D 记忆”和“如何鲁棒使用记忆”两个角度出发，填补了现有工作在避免循环编码和缩小 train‑test 分布差距上的空白。

### English Summary
Existing 3D-aware memory methods suffer from repeated VAE encode‑decode degradation (Latent–RGB Cycling) and a severe train–test mismatch where training sees only clean memory but inference sees prediction‑corrupted memory (error‑free hypothesis). This causes catastrophic drift in long autoregressive rollouts. The paper directly tackles both issues.

---

## 核心方法 / Core Method

### 中文概述
Robust Dreamer 是一个记忆增强的自回归生成框架，整体流程如下：
- **Latent Gaussian Memory（潜变量高斯记忆）**：将生成过程（DiT 去噪后）直接继承的潜变量锚定在带有几何属性（中心点、旋转、尺度、透明度）的 Gaussian 原语上，构成持久 3D 记忆。写入时，利用基于 CUT3R 风格的前馈重建模块估计全局几何，将当前帧潜变量按像素对齐写入对应的 Gaussian 原语；召回时，在潜空间直接对 Gaussian 原语做 alpha 合成 splatting，得到与目标视角对齐的稠密潜变量条件，完全避开 VAE 解码‑编码。
- **Deviation Learning with Dynamic Deviation Archive（偏移学习与动态偏移存档）**：为覆盖训练‑推理 gap，在训练时对历史帧的潜变量注入合成偏移。偏移通过一步近似（one‑step approximation）模拟 rollout 中累积的潜变量误差，并按自回归步数和去噪时间戳分层存入动态存档。训练时从存档采样偏移加入历史记忆条件，使去噪网络学会从被污染的记忆中恢复干净未来帧。
- 推理时，Dreamer 接受四个条件：干净锚帧、当前帧、由记忆 splatting 生成的对齐潜变量、控制信号，预测下一帧。

### English Summary
Latent Gaussian Memory stores diffusion latents on Gaussian primitives with feed‑forward geometry prediction and recalls them via latent‑space splatting, avoiding VAE cycling. Deviation Learning uses a Dynamic Deviation Archive of one‑step approximated rollout errors, injected during training to teach the generator to correct corrupted memory, closing the train‑test gap.

---

## 启发性分析 / Insight Analysis

### 中文概述
- **消融实验**（文中包含完整的成分消融）：移除 Deviation Learning 会导致长程生成时结构崩溃，证明显式建模记忆污染对鲁棒性至关重要；用 RGB 记忆替代 Latent Gaussian Memory 会因重复 VAE 转换积累退化，表明潜变量级记忆是维持细节的关键。
- **定性分析**：Fig.2 直观展示了无偏移训练与有偏移训练的巨大差异——前者在 35 步循环后出现严重的颜色失真和几何坍塌，后者显著缓解漂移、保留几何细节。
- **反直觉/深度洞察**：仅用一步近似合成偏移就能有效缩小 gap，说明 rollout 偏移的分布可以被低阶近似捕捉；将偏移按 AR 阶段和去噪时间戳分层存档，比简单的随机噪声注入更有教学价值，因为这更贴近实际推理中的记忆污染特征。
- **理论与扩展性**：框架将几何（Gaussian splatting）与内容（潜变量）解耦，便于后续引入动态 4D 表征（文中已提及 4DGS 扩展），并可与不同的视频 DiT 骨架兼容。

### English Summary
Ablations confirm both components are essential: removing deviation learning leads to structural collapse, and switching to RGB memory degrades quality due to VAE cycling. The one‑step deviation approximation is surprisingly effective, and stage‑wise archiving (AR stage + denoising timestamp) provides a more targeted training signal than random noise.

## 局限性与展望 / Limitations & Future Work

### 中文概述
**作者承认的局限**（详见附录 Limitations 节）：
- 记忆写入依赖 3D 重建模块（前馈高斯预测）的质量，在遮挡、镜面反射、快速运动或视角不足时几何精度下降，可能导致记忆污染。
- 当前框架为模块化设计（重建模块 + DiT 生成器），并非完全端到端训练，可能限制整体效能提升。
- 动态场景虽已尝试 4DGS 扩展，但快速运动物体的记忆精确性仍有待改善。

**未明确提及但可能存在的局限**：
- 合成偏移的一步近似是否在所有场景下都足够表征长期累积误差尚需更极端的测试（如极长 horizon）。
- 3D 记忆的存储和 splatting 计算开销在高分辨率下可能较大，影响实时交互性能。
- 目前仅在固定数据集上测试，迁移到完全开放世界的泛化性未验证。

**未来方向**：端到端联合优化 3D 重建与视频生成；将框架与更强的基础视频模型（如 Veo3 等）结合；在真实的 embodied agent 任务中评估规划能力。

### English Summary
Acknowledged limitations: dependence on 3D reconstruction quality (struggles with occlusions, reflections, rapid motion), modular (not end‑to‑end) design. Unmentioned: scalability of deviation archive to very long horizons, computational cost of latent splatting at high resolution, out‑of‑distribution generalization. Future work includes end‑to‑end training and real embodied agent evaluation.

## 个人思考 / Personal Takeaways

- **方法优雅且工程实用**：将 3D Gaussian Splatting 用于潜变量级记忆是极其自然的结合，既保留了溅泼的可微性，又契合扩散模型的原生潜空间，且继承了高斯原语的紧凑性。Deviation Archive 用一个简单的误差银行解耦了训练与推理的分布偏移，思路清晰。
- **可迁移性高**：该记忆框架不限于特定的 DiT 或 VAE，可轻易嫁接至当前流行的任何自回归视频模型。后续研究可将其作为长程世界模拟的即插即用模块。
- **关键洞察**：潜变量空间中的“几何保持”比 RGB 空间更具优势，因为避免了码本的量化损失；另外，显式模拟记忆漂移并不仅仅是注入噪声，而是注入“结构化”的近似误差（按 stage 存档），这一做法可能对强化学习中的 world model 也有启发。
- **潜在质疑**：前馈 3D 重建模块的精度决定了记忆质量的上限，若几何错误，后续 splatting 会产生严重的错位 ghost 问题。实际部署时可能需要在线重定位或测试时优化来弥补。
- **研究启发**：可将 Deviation Learning 思想推广到其他 autoregressive 生成任务（如文本、音频），设计对应的误差存档和注入策略；同时，结合 latent-space 的 rolling memory 也可能为基于扩散模型的 planning 提供更连贯的隐式环境模型。

# DecMem: Towards Minute-Long Consistent World Generation with Decoupled Memory

**Authors**: Zhenhao Yang, Xiaoshi Wu, Zhengyao Lv, Xiaoyu Shi, Xintao Wang, Pengfei Wan, Kun Gai, Kwan-Yee K. Wong
**Venue**: arXiv
**Link**: https://arxiv.org/abs/2605.31336
**PDF**: https://arxiv.org/pdf/2605.31336

## 动机 / Motivation

### 中文概述
- 长视频世界模型的核心挑战是在长时间推理中保持细粒度时空一致性，尤其在“重访”场景下现有模型难以回忆已生成内容，导致严重的不一致。
- 现有记忆机制存在瓶颈：显式 3D 记忆受限于 3D 估计器的精度与累积误差；隐式记忆（FOV 检索或基于注意力）受限于粗粒度的帧级建模，无法捕捉子帧级时空对应。
- 最直接的全历史密集注意力虽实现可学习的细粒度记忆，但带来**注意力分散**（大量弱相关 token 稀释关键 token 的权重，导致质量崩塌）和**计算效率呈线性增长**，无法扩展至分钟级。
- 训练无关的衰减策略虽缓解局部失真，却无差别地抑制所有远距离信息，切断了真正的长程依赖，暴露出短期保真度与长期一致性之间的根本权衡。
- 出发点：需要一个可学习、自适应的架构，既能高效访问全局历史，又能保持注意力集中，从而打破上述两难困境。

### English Summary
Maintaining fine-grained spatio-temporal consistency in long video generation is challenging, especially in revisit scenarios. Existing memory mechanisms are either fragile (3D estimators) or limited to frame-level retrieval. Naïve dense attention causes attention dispersion and prohibitive cost, and training-free decay sacrifices long-range memory. The work is motivated by the need for a learnable architecture that can efficiently access global history while preventing attention dilution.

## 核心方法 / Core Method

### 中文概述
- **整体框架**：基于自回归视频生成和动作条件化的世界模型，在 Transformer 中注入动作嵌入实现可控生成。
- **解耦记忆架构 DecMem** 包含两个互补模块：
  - **稀疏全局记忆 (SGM)**：对完整历史进行可学习的**块级稀疏检索**（block-level sparse retrieval），仅选取最相关的历史块参与注意力计算，实现高效且细粒度的全局记忆访问。
  - **锚定局部记忆 (ALM)**：在最近若干帧上执行密集注意力，为查询提供稳定、高权重的局部上下文，以**显式对抗注意力的分散**。
- 通过解耦全局检索与局部锚定，SGM 维持长程一致性，ALM 保证短程保真度与稳定外推，从而同时解决注意力分散和计算效率两大难题。
- 与最相关工作的区别：不同于基于 FOV 的帧级启发式检索（WorldMem 等），SGM 是端到端可学习的**子帧级**检索；不同于训练无关的窗口衰减，ALM 不丢弃任何历史信息，仅通过局部锚定稳定注意力分布。

### English Summary
DecMem is a decoupled memory architecture for action-conditioned autoregressive video world models. It consists of Sparse Global Memory (SGM), which performs learnable block-level sparse retrieval over the full history for efficient fine-grained global access, and Anchored Local Memory (ALM), which applies dense attention on recent frames to provide stable local anchoring. This decoupling simultaneously mitigates attention dispersion and computational blow-up, unlike frame-level heuristic retrieval or training-free decay.

- **注意力分散的根源**：通过可视化长视野推理的注意力图，作者揭示随着序列增长，大量弱相关的历史 token 以微小但非零的权重充斥注意力分布，形成长尾分布，严重稀释了对关键历史帧的有效注意力权重，这是质量崩塌和结构坍塌的直接原因。
- **训练无关策略的本质缺陷**：机械地衰减远距离 token 会无差别抑制所有窗口外信息，彻底切断真实的长程依赖，表明手工设计的注意力先验无法从根本上平衡保真度与一致性。
- **架构洞察**：需要的不是一个更复杂的注意力先验，而是一个能够自适应抑制冗余、同时显式提取对记忆保留有帮助的历史信息的可学习架构。解耦设计完美契合这一需求——SGM 负责紧凑地“拾取”关键信息，ALM 负责“锁定”局部稳定分布。

## 个人思考 / Personal Takeaways

- DecMem 的解耦设计为长视频世界模型提供了一个概念清晰的解决方案：将记忆的“全局检索”与“局部稳定”解耦，本质上是在信息获取和抗噪之间做了合理的功能划分，这种设计哲学可以推广到其他长序列任务（如长文档理解、具身 AI 的记忆系统）。
- 可学习的块级稀疏检索是一种轻量而有效的注意稀疏化方式，相比固定规则或帧级检索，保留了端到端优化的能力，同时显著降低成本，这对资源受限下的长上下文 Transformer 很有启发。
- 注意力分散的现象学分析和 ALM 的锚定思想值得深入思考：它暗示我们不一定需要全局上下文窗口内所有 token 的密集交互，关键往往在于局部锚点的稳定性和全局关键信息的精准注入。
- 论文缺失了具体的实验细节和消融研究，使得一些架构选择（如 block 大小、稀疏度、ALM 窗口长度）的敏感性无法评估，这是跟进研究时首先需要补充的。
- 从工程角度，后续可以将稀疏检索模块进一步蒸馏或与高效注意力实现（如 FlashAttention）结合，向实时世界模型迈进；理论上，值得探索自监督的检索信号来提升关键块选择的准确性。
