# When Vision Becomes Text: Visual Token Pruning via Cross-Modal Residual Guidance in VLMs

**Authors**: Congyang Ou, Ruike Song, Yang Zhou, Libo Sun, Haokui Zhang, Zhenbo Luo
**Venue**: arXiv
**Link**: https://arxiv.org/abs/2608.10489
**PDF**: https://arxiv.org/pdf/2608.10489
**Importance**: 高优先级 (94.22)
**Why selected**: Directly targets efficient multimodal inference via training-free visual token pruning, aligning with the user's model efficiency and continuous multimodal priorities. Signals: visual token pruning, training-free, KV cache reduction, prefill speedup, cross-modal residual
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

提出 SIEVE，一种免训练的视觉 token 压缩方法，通过量化文本逐步吸收视觉信息的过程并保留文本无法解释的残差信息，在仅保留 11.1% 视觉 token 下保持 97.5% 的性能。
SIEVE is a training-free visual token pruning method that preserves task-critical tokens by measuring the amount of visual information unexplainable by text, achieving 97.5% average performance with only 11.1% visual tokens retained.

---

## 动机 / Motivation

### 中文概述
- **要解决的问题**：视觉语言模型（VLM）推理时大量视觉 token 导致高计算开销、延迟和 KV 缓存膨胀，尤其是高分辨率、多图像和视频输入场景。
- **现有方法的不足**：当前视觉 token 剪枝方法主要基于注意力分数或 token 相似度，这些信号仅捕捉单层局部状态，缺乏对整个多模态推理过程的全局视角。
- **核心观察与出发点**：作者重新审视 VLM 推理过程，发现随着层加深，文本 token 通过自注意力持续聚合视觉信息，逐步将部分视觉内容吸收到文本表示中（如图 2 所示，CMA 随层单调增加）。这意味着许多视觉信息可被文本子空间解释，真正需要保留的应是文本无法解释的残差部分。

### English Summary
Existing pruning methods rely on local layer-level similarity signals, ignoring that during VLM inference, text tokens progressively absorb visual information via self-attention. This work introduces a global view that quantifies this absorption and retains only the visual information that cannot be explained by text.

---

## 核心方法 / Core Method

### 中文概述
- **整体框架**：SIEVE 是一种即插即用的免训练压缩方法，在 VLM 的若干选定层中对视觉 token 进行一次性评分和选择，后续层复用缩短后的序列。
- **核心机制**：
  1. **跨模吸收 (CMA)**：从几何表示角度，测量每一层中能被文本子空间解释的视觉 token 比例。发现深层 CMA 显著升高，说明视觉信息逐步融入文本空间。
  2. **跨模残差 (CMR)**：将每个视觉 token 通过 Tikhonov 正则化最小二乘投影到文本子空间，用重建残差量化“文本无法解释的视觉信息”。残差越大，token 的独特性越高，保留必要性越强。
  3. **SIEVE 的三重选择策略**：
     - **CMR 评分**：保留具有独特视觉信息的 token。
     - **注意力相关性评分**：利用文本-视觉注意力权重，保留与任务相关的 token。
     - **残差空间多样性选择**：在残差空间中计算 token 相似度，进行贪心去冗，优先保留互补性强的 token。
- **与现有工作的区别**：不同于仅依赖相似度或注意力的方法，SIEVE 利用跨模吸收动力学，聚焦于文本表示无法解释的残差信息，是一个跨层视角的互补性指导信号。

### English Summary
SIEVE projects visual tokens onto the text subspace via Tikhonov-regularized least squares and uses the reconstruction residual (CMR) to retain tokens carrying unique visual information unexplainable by text. Together with attention relevance and residual-space diversity, it selects a compact, task-relevant token set at a few pruning layers, without any training.

## 启发性分析 / Insight Analysis

### 中文概述
- **逐层吸收现象**：在 LLaVA-1.5-7B 的 32 层中，CMA 从约 10% 单调上升至约 40%，且在 TextVQA、POPE、MME 等多个基准上高度一致（ρ = +0.99），说明深层视觉 token 逐渐向文本子空间靠拢具有很强的跨任务稳定性。
- **注意力和 CMR 的信号互补性**：提取文本中提到覆盖分析（Cov@k）显示两种排名信号的重叠度极低（平均仅 11.54%），即注意力主要反映查询相关的语义显著性，而 CMR 捕获几何上文本无法解释的独特性。单用任一信号都会丢失重要维度，融合二者能覆盖更完备的视觉证据，解释了 SIEVE 性能优势。
- **效率分析**：SIEVE 的评分开销主要在 O(N²d) 的残差空间相似度计算，但只发生在少量剪枝层，而缩短序列在后续所有层都节省自注意力和 FFN 计算，这种“一次评分，多层受益”的模式在长视觉序列场景下加速效果尤为显著。
- **反直觉发现**：视觉信息并非始终保持独立，而是在前向传播中动态地被文本表示吸收整合——这打破了视觉 token 冗余只是静态冗余的假定，为跨模态压缩提供了新视角。

### English Summary
CMA increases monotonically and consistently across layers and benchmarks. Attention and CMR signals are highly complementary (overlap ~11.5%), explaining why their combination outperforms either alone. The one-time scoring, multi-layer saving pattern makes the method efficient, especially for long visual inputs.

## 局限性与展望 / Limitations & Future Work

### 中文概述
- **作者讨论的局限**：
  - 评分开销主要来自残差空间相似度矩阵计算，在少数剪枝层引入 O(N²d) 成本，虽然通过单次评分多层受益可在长序列下加速，但短序列或极小模型上可能不满足净加速条件（文中给出了加速不等式）。
  - 当文本 token 很长时，构建文本子空间和 Tikhonov 投影成本可能上升，建议使用固定窗口或限制有效秩。
- **未提及的潜在局限**：
  - 剪枝层的选择（位置和数量）如何影响最终性能？提取文本未给出剪枝策略的通用原则或自适应选择机制。
  - 对不同 VLM 架构（如具有交叉注意力的模型）的泛化性尚需验证，当前评估限于 LLaVA 和 Qwen2.5-VL 架构。
  - 在需要精确定位或细粒度视觉推理的任务上，残差保留策略是否会导致空间信息的丢失缺少定性分析。
- **未来方向**：可探索动态剪枝层选择、自适应 token 预算分配、支持交叉注意力架构的扩展，以及结合量化或蒸馏进一步压缩。

### English Summary
The scoring overhead may hinder net acceleration in very short sequences. The pruning layer selection and budget allocation currently lack adaptivity. Generalization to cross-attention VLMs and tasks requiring fine-grained spatial details remains unexplored.

## 个人思考 / Personal Takeaways

- **方法论启示**：利用模型自身 forward 动力学（视觉 token 向文本子空间靠拢）设计剪枝信号，是一种优雅的“以模型解释模型”的策略。这种从几何表示角度定义跨模态吸收的思路可推广到其他模态（如音频、视频流）或多轮交互场景。
- **互补信号融合**：实验揭示的注意力与 CMR 极低重叠是有价值的洞察，说明语法/语义相关性与视觉独特性在多模态推理中往往是正交的维度。未来工作可在此基础上引入第三维信号（如 grounding 或概念层级）。
- **与当前趋势的关联**：该工作属于“免训练压缩”家族，但其背后依赖的 CM A/CMR 指标可能作为软标签用于训练阶段的蒸馏或 token 重要性学习，实现更高压缩率或更灵活的预算控制。
- **潜在风险**：残差是基于文本子空间定义的，当文本 prompt 语义模糊或存在歧义时，文本子空间可能不稳定，从而导致剪枝遗漏关键视觉证据。在实际部署中需对这种边缘情况做鲁棒性评估。

# Stream Forcing: Constructing Unified Training Trajectory for Robust Streaming Video Generation

Signals: video world model, streaming video generation, diffusion video generation, train-inference mismatch, long-horizon extrapolation  
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

## 一句话总结 / One-liner

提出 Stream Forcing，一种通过构建连续训练轨迹统一独立采样与推理一致采样的流式视频扩散模型训练框架，显著缓解训练-推理不匹配问题，并在长时视频外推上展现鲁棒性。  
Stream Forcing proposes a continuous training trajectory that bridges independent and progressive noise-level sampling to resolve the train-inference mismatch in streaming video diffusion, achieving strong long-horizon extrapolation.

---

## 动机 / Motivation

### 中文概述
- **问题**：流式视频扩散模型在训练和推理之间存在根本性不一致（train-inference mismatch）。推理时要求按照特定的单调去噪顺序（progressive sampling），而先进训练策略需要多样化的噪声水平配置（independent sampling）来保证分布覆盖。
- **现有工作的差距**：已有的两种训练范式各有侧重：progressive sampling（如 rolling diffusion [35]）训练-推理一致但噪声分布覆盖窄，导致模型泛化受限；independent sampling（如 diffusion forcing [6]）覆盖广但完全忽略推理时的时间依赖结构，导致性能下降。二者存在覆盖度与一致性的 trade-off，现有方法未能统一。
- **关键观察与出发点**：两种训练策略本质上是互补的：independent sampling 具有帧间不变的噪声分布和零时间相关性，而 progressive sampling 在极限下呈现帧依赖偏差和强时间相关性。作者将训练时噪声水平采样重新定义为帧索引的随机过程，从而在同一个参数空间中同时容纳这两种策略，并将其作为连续课程（curriculum）的两个端点，以便在训练过程中平滑过渡。

### English Summary
Streaming video diffusion models suffer from a conflict between inference-consistent noise-level assignment (progressive sampling) and diverse noise coverage (independent sampling). Existing methods treat them separately, creating a trade-off. The paper reframes per-frame noise-level sampling as a frame-indexed stochastic process parameterized by Logit-Normal distributions, enabling both paradigms to coexist in a unified space. This reformulation allows the construction of a continuous training trajectory that gradually transitions from independent to progressive sampling, balancing distribution coverage and inference alignment.

---

## 核心方法 / Core Method

### 中文概述
- **整体框架**：Stream Forcing 是一个统一的课程训练范式，在训练过程中沿着一条连续轨迹逐步将对齐推理的采样策略融入模型。
- **核心机制**：
  1. **随机过程重构**：将训练窗口内每一帧的噪声水平采样视为一个以 Logit-Normal 为边缘分布的随机过程，由帧级别的位置参数 (μ_t)、尺度参数 (σ_t) 和帧间相关系数 (ρ) 共同描述。独立采样对应 μ_t = μ_0, σ_t = σ_0, ρ = 0；理想 progressive sampling 对应 μ_t → logit(t/T), σ_t → 0, ρ → 1。
  2. **连续训练轨迹**：在该参数空间中将两种极端配置作为端点，构造一条满足三个约束的连续路径：
     - *平滑过渡*：各帧边缘分布的众数（mode）沿训练步骤均匀移动（避免突变）。
     - *帧间覆盖一致*：同一训练步内不同帧的边缘分布在众数处密度相同，保证每帧获得相似的噪声分布覆盖。
     - *时间相关性*：相关系数 ρ 随训练推进逐渐增大，保持帧间依赖。
  3. **联合校准与相关采样算法**：利用 **Joint Calibration** 算法（Alg.1）通过启发式网格搜索确定每一步的 (μ_t, σ_t)，使得众数密度匹配参考值 H（多为中位数），从而满足平滑与覆盖约束；同时引入基于 Gaussian Copula 的 **Temporal Correlative Sampling** 算法，根据指定的 ρ 生成具有帧间相关性的噪声水平序列，确保样本沿轨迹保持合理的时间依赖。
- **与最相关工作的区别**：不同于 Diffusion Forcing [6] 仅使用独立采样，或 Rolling Diffusion [35] 仅使用单调递增的确定性噪声调度，Stream Forcing 通过显式构建连续参数课程，首次在训练中同时享有独立采样的多样性覆盖和渐进采样的推理一致性，且无需在推理时改变任何模块。

### English Summary
Stream Forcing models per-frame noise level sampling as a Logit-Normal-margined stochastic process with mean, variance, and inter-frame correlation parameters. It then constructs a continuous training trajectory that interpolates between the independent-sampling baseline (wide coverage, no correlation) and a strongly progressive endpoint (strict temporal ordering, inference-aligned). Two algorithms—joint calibration for smooth, balanced marginal modes and Gaussian-copula temporal sampling for correlation—ensure the trajectory smoothly evolves without abrupt distribution shifts. This unified curriculum framework directly addresses the coverage–consistency trade-off.

## 启发性分析 / Insight Analysis

### 中文概述
- **消融与定性分析揭示的关键发现**（从已提取的实验描述推断）：
  - 相比于单纯的独立采样或 progressive 采样，Stream Forcing 在 UCF-101 上取得 **36.6% FVD 提升**，在 Taichi-HD 上取得 4.7% 提升，说明课程路径比固定策略更有效。
  - 长时视频零样本外推（zero-shot extrapolation）实验中，Stream Forcing 获得 **27.9% FVD 改善**，证明训练轨迹中逐渐内化的时间依赖结构能泛化到更长的生成序列，这对世界模型和具身推理至关重要。
  - 在自主驾驶数据集 nuScenes 上同步改善 FID 和 FVD，暗示方法有望扩展到复杂动态世界建模。
- **反直觉发现**：
  - 训练时直接使用 deterministic progressive schedule 通常会导致模型训练不稳定或性能差；本文通过概率化的连续过渡（维持一定随机性）反而得到更好的推理一致性，说明“硬”对齐并不如“软”课程过渡有益。
- **缩放、泛化或理论相关洞察**：
  - 该方法本质上是一种训练抽样策略，对扩散模型本身结构无侵入性修改，因此具备较好的可移植性。
  - Gaussian Copula 引入的帧间相关性控制，为更显式地调节视频时间连贯性提供了把手，可能启发未来可控视频生成的研究。
- **不足**：论文中未提供详尽的消融研究（如轨迹曲率、相关系数曲线形状等）的深度分析，也未讨论不同视频类型下约束敏感度的差异。这些在完整论文中可能存在，但从现有文本难以明确判断。

### English Summary
The experiments indicate that a curriculum blending broad coverage and structured temporal dependency yields substantial FVD gains over either fixed strategy alone. The soft transition along the parameter trajectory (via Gaussian Copula and calibrated marginals) is more effective than a hard switch, supporting the idea that training randomization should not be abandoned entirely. The strong zero-shot long-horizon results demonstrate that the method effectively learns time-consistent representations that generalize. However, extracted text provides no detailed ablation on trajectory shape or inter-frame correlation schedules, limiting deeper insight.

## 核心方法 / Core Method

### 中文概述
整体框架是一个从多模态观察到连续轨迹的端到端模型，核心创新在于插入了一种 **Executable Chain-of-Thought (XCoT)** 作为推理-动作接口。

**1. 离线 XCoT 监督数据构建**
- **动作证据提取**：从记录的轨迹中提取纵向和横向运动模式（如减速、换道）。
- **语义接地**：利用视觉-语言专家对动作的原因进行归因（导航意图、交通规则、交互、安全），并通过共识机制选出一致的原因。
- **语义压缩**：将“原因-动作对”映射为 2-6 个规范化的 XCoT token 序列（如 `LEFT_TURN_PREPARE, DECELERATE, RED_LIGHT_HOLD`）。

**2. 模型推理与轨迹生成**
- 模型首先自回归生成 XCoT token 序列（仅 2-6 个 token，远少于几十个字的自然语言）。
- 生成的 XCoT token 与固定的轨迹查询 token 一起进入 shared multimodal self-attention。
- **确定性 token 函数路由**：XCoT token 送入 Reason FFN，轨迹查询 token 送入 Control FFN，实现计算解耦。
- 轨迹查询通过 Flow Matching decoder 生成未来 24 步的加速度和横摆角变化序列，再积分得到轨迹。

**3. 可选扩展：XCPO 策略优化**
- 在固定轨迹执行器（Control FFN + Flow Matching head）的前提下，用 RL 优化 XCoT 推理策略，使其产生更好的推理 token 序列以最大化轨迹级奖励。
