# Latent Spatial Memory for Video World Models

**Authors**: Weijie Wang, Haoyu Zhao, Yifan Yang, Feng Chen, Zeyu Zhang, Yefei He, Zicheng Duan, Donny Y. Chen, Yuqing Yang, Bohan Zhuang
**Venue**: arXiv
**Link**: https://arxiv.org/abs/2606.09828
**PDF**: https://arxiv.org/pdf/2606.09828
**Importance**: 高优先级 (97.15)
**Why selected**: Directly advances video world models with a novel latent-space memory that dramatically accelerates generation and reduces memory, aligning with top user priorities. Signals: world model, video generation, diffusion latent space, 3D spatial memory, 10.57x speedup
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

Mirage 提出在扩散潜空间中直接构建三维空间记忆，通过潜 token 反投影与潜空间扭曲合成新视角，彻底避免了 RGB 点云记忆反复渲染和 VAE 编码的开销与信息损失，实现最高 10.57 倍端到端加速与 55 倍内存缩减。  
Mirage stores 3D spatial memory directly in diffusion latent space via depth-guided back-projection and latent-space warping, eliminating the costly render-and-encode loop of RGB point clouds and achieving up to 10.57× speedup and 55× memory reduction.

---

## 动机 / Motivation

### 中文概述
- 现有视频世界模型靠显式 RGB 点云维持三维一致性，每一帧生成都需将点云渲染为 RGB 图像再经 VAE 编码为潜在信号（rasterize-and-encode round trip），这带来两大瓶颈：（1）计算极其昂贵——渲染数百万彩色点在像素空间运行，每次都要重新编码；（2）RGB 绕行丢失了扩散模型原生的潜在表征，VAE 重建误差、栅格化伪影和分布失配导致条件信号失真。
- 该工作的核心洞察：扩散模型的生成本身就工作在 VAE 潜在空间，因此空间记忆完全可以直接存储和查询潜在特征，而不是 RGB 颜色。这样可以一举消除像素级渲染和每步 VAE 编码的依赖，同时保留高保真潜在特征。
- 所解决的研究空白：缺少一种完全在潜在空间中操作的持久化 3D 缓存，以支撑长程、相机可探视的世界生成，并解决几何漂移问题。

### English Summary
Existing video world models use explicit RGB point clouds for 3D consistency, requiring a costly per-step rasterize-and-reencode loop. This introduces two bottlenecks: heavy computation at pixel resolution, and loss of original latent features due to reconstruction artifacts. The key insight is to store and query the memory directly in the VAE latent space where the diffusion model natively operates, eliminating pixel-space round trips and preserving feature fidelity. This addresses the lack of a persistent 3D memory that works purely in latent space for long-horizon, exploration-style generation.

## 核心方法 / Core Method

### 中文概述
- **整体框架 (Mirage)**：采用“初始化-读取-更新”的循环。用一个初始帧编码并反投影深度引导的潜在 tokens 到 3D 缓存（点 = 世界坐标 + 向量）中；对每一块(chunk)目标帧，直接将缓存投影到目标相机网格（潜分辨率）生成视角特征张量，通过 ControlNet 风格侧支路注入扩散骨干，无需中转 RGB；生成的帧再估算深度、分割动态对象、重新编码并反投影回缓存，以更新记忆。
- **核心机制**：
  - **潜在空间记忆构建**：给定编码后的潜在张量 以及估计的深度，将每个潜在网格单元反投影到世界空间，形成 (坐标, 潜在特征) 对。
  - **记忆读取**：目标视角下，所有记忆点通过 z-buffer 投影到潜分辨率网格，取最近点，直接提取对应潜在 token，生成目标视图的潜在特征和可见性遮罩；遮罩用于区分未观测区域。
  - **缓存更新**：新生成的 chunk 再被 VAE 编码回潜在空间，经动态物体过滤后加入缓存，只保留静态几何内容，避免动态物体污染。
- **与最近工作的区别**：与传统 RGB 点云方法（如 [11-14]）相比，Mirage 的读写均直接在 VAE 潜在空间进行，不需要逐帧渲染-编码，使读写成本和内存占用均压缩 倍（ 为 VAE 空间下采样步长）。

### English Summary
Mirage operates in an initialize-readout-update loop. The cache stores world-coordinate/latent-feature pairs, built by depth-guided back-projection of VAE latents. At readout, points are projected to the target latent grid with z-buffering, directly yielding latent features for conditioning via a ControlNet side branch. Updates re-encode generated frames, filter dynamic objects, and back-project static latents. Unlike RGB point clouds, all memory operations avoid pixel-space rendering and VAE encoding/decoding in the critical conditioning path, shrinking memory by the squared VAE compression factor.

## 启发性分析 / Insight Analysis

### 中文概述
- **消融分析揭示的核心发现**：
  - 直接存储和查询潜在特征保留了扩散模型的原生条件分布，避免了 RGB 重建带来的信号退化；实验表明这带来了质量提升和更快的推理。
  - 通过 ControlNet 支路注入记忆特征允许骨干保持预训练，仅需微调侧网络，既保证生成质量又保持兼容性。
  - 动态物体过滤对记忆更新至关重要：加入动态物体（如行人、车辆）会破坏缓存几何一致性，因此只保留静态区域。
- **反直觉发现**：传统观点认为点云需要着色才能为生成器提供可解释的条件，但工作表明扩散模型能直接利用潜在空间的高维特征，甚至比 RGB 信号更强，因为其保留了更丰富的语义和几何线索。
- **规模化与泛化**：内存和计算复杂度从原本的像素空间规模转变为潜在空间规模，意味着随分辨率增加（如到 1K 或更高），潜在记忆的相对优势会进一步放大。此外，该方法对 VAE 下采样步长 敏感，因为缓存压缩比 倍，实际部署可借此灵活平衡质量与效率。
- **论文若缺乏深入洞察分析则声明**：论文在实验部分提供了定量比较和效率数据，但未深入分析不同层级的潜在特征对记忆质量的影响，也未探索记忆大小的自适应修剪或长序列下的累积漂移定量分析。

### English Summary
Ablation insights: storing latent features directly preserves native conditioning signal and avoids RGB reconstruction loss; ControlNet-style injection allows frozen backbone fine-tuning; dynamic object filtering is essential for cache geometric integrity. Counterintuitively, high-dimensional latent features serve as more powerful conditioning than RGB colors. Scaling analysis implies larger advantages at higher resolutions due to the squared compression factor. The paper lacks deep analysis of per-layer feature importance, adaptive pruning, or quantitative drift accumulation over long rollouts.

## 局限性与展望 / Limitations & Future Work

### 中文概述
- **作者承认的限制**：动态对象过滤导致 Mirage 不维护动态角色的状态（如行人、车辆），因此对动态占主导的场景优势较小，持久化动态内容跨 chunk 是未来方向。
- **未提及的重要局限**：
  - 依赖深度估计质量；若深度估计不准，潜在 token 反投影会有位置误差，可能引入空穴或错位，尤其对透明、镜面、细薄结构。
  - 潜在记忆可能遭遇特征维度灾难，随着缓存增长，读操作复杂度增长；虽然内存比 RGB 小，但对极大场景管理仍需要更精巧的索引或蒸馏策略。
  - 该方法未讨论在真实机器人或交互式环境中动作条件而非仅相机轨迹下的泛化能力。
- **未来方向**：作者提议研究动态实体持久化；此外，可考虑自适应缓存稀疏化、与 3D Gaussian Splatting 等高效表示结合，以及扩展到多模态世界模型（如动作、物理参数驱动）。

### English Summary
Authors acknowledge dynamic object filtering means no persistent state for moving agents; future work includes persisting dynamic content. Unmentioned limitations: heavy reliance on accurate depth estimation, potential feature redundancy in large caches, and lack of action-conditioned evaluation. Future directions: adaptive cache sparsification, integration with explicit 3D representations like 3DGS, and extensions to interactive world models.

## 个人思考 / Personal Takeaways

- **核心创新极简且高效**：将世界模型的空间记忆从像素空间迁移到潜在空间的思路看似直接，但一举解决了计算瓶颈和信号损失两大痛点，且实现干净，避免了复杂的跨空间转换模块。这为所有在潜在扩散模型上构建持久 3D 表示的工作提供了新范式。
- **潜在特征质量的隐含假设**：该方法假设 VAE 潜在特征在空间反投影后能保持足够的几何和纹理信息，实际上这依赖于 VAE 的表示质量和深度估计精度。未来可探索联合训练深度估计和潜在表征，或使用更富含几何信息的潜在特征（如来自 3D VAE）。
- **对视频生成的新思考**：该方法本质是将生成过程与持久记忆分离，生成器只是“填空”工具，而记忆提供刚性几何支架，这解耦了即时外观与长期一致性的关系。对具身智能中的视觉预言（visual foresight）和环境想象有很大的借鉴价值。
- **可扩展性及落地考量**：10.57× 加速和 55× 内存缩减使得在消费级 GPU 上生成长程一致性视频变得可行，有望推动实时交互式世界模型的发展。如果将内存读取设计为可插拔模块，可快速适配各类新出的 DiT 骨干。

# Enabling KV Caching of Shared Prefix for Diffusion Language Models

**Authors**: Younghun Go, Jaehoon Han, Changyong Shin, Chuk Yoo, Gyeongsik Yang
**Venue**: arXiv

**PDF**: https://arxiv.org/pdf/2606.07571

**Why selected**: Directly addresses a critical efficiency bottleneck for continuous language models, a top priority subtopic. Signals: First KV caching for diffusion language models, addresses bidirectional attention challenge, significant throughput improvement (36-98%), no accuracy collapse, aligns with efficient inference priority
**Source note**: PDF full text extracted; high-value sections were selected for the model context.

---

## 一句话总结 / One-liner

中文：bicache 首次针对扩散语言模型的双向注意力特性，通过浅层重用共享前缀 KV 并动态确定安全层深度，在无精度崩溃的前提下实现 36.3%–98.3% 的吞吐提升。

English: bicache is the first KV caching technique for diffusion language models that reuses shared prefix KVs in shallow layers with dynamic depth selection, achieving 36.3%–98.3% throughput improvement without accuracy collapse.

---

## 动机 / Motivation

### 中文概述
- 背景：扩散语言模型（DLM）采用双向注意力，每一步任何一个 token 的变化都会动态改变全部上下文及其对应的 KV 向量。因此，自回归模型（ARM）中假设“一次计算、永久不变”的共享前缀缓存技术直接用到 DLM 上会导致模型精度崩溃至近零值。
- 现实需求：实际部署中共享前缀（如系统提示、多轮对话历史）占请求 token 的 85–97%，必须重用这部分 KV 才能实现高吞吐服务。但现有 DLM 加速工作（如 Fast-dLLM、dLLM-Cache）仅关注单请求内 KV 重用，未解决跨请求的共享前缀缓存。
- 核心观察起点：分析发现在浅层，共享前缀 KV 跨请求仍保持较高相似度；且安全重用的层深度与每个请求中共享前缀 token 的比例高度相关，这为选择性缓存提供了基础。

### English Summary
DLMs use bidirectional attention, so any token update changes all context KVs, breaking the invariance assumption of ARM-style shared prefix caching and causing accuracy collapse. Shared prefixes dominate real workloads (85–97% of tokens), yet no existing DLM caching supports cross-request prefix reuse. The paper starts from the observation that shallow-layer shared prefix KVs remain similar across requests, and the safe layer depth correlates with the shared prefix ratio in each request.

---

## 核心方法 / Core Method

### 中文概述
- 整体框架：bicache（bidirectional prefix caching）包含两个阶段：离线剖析（shared prefix profiling）与在线服务（layer-partitioned caching）。
- 核心机制：
  1. **剖析阶段**：利用少量请求（~500）测量共享前缀 KV 在各层各步的跨请求余弦相似度。基于相似度阈值 τ（如 0.97）和每个请求的共享前缀 ratio，学习一个从 ratio 到安全层深度 b 的映射（lookup table）。该映射遵循“ratio 越高，可安全重用的层越深”的规律。
  2. **服务阶段**：将 Transformer 层划分为浅层（≤b）和深层（>b）。浅层直接复用已缓存的共享前缀 KV（跨请求重用）；深层则采用周期性刷新（periodic refresh），即每 ∆ 步重新计算一次 KV，并在 ∆ 步内跨步骤重用，从而减少深层冗余计算。
- 与最相关工作的区别：vLLM 等 ARM 缓存方案对所有层和所有步直接重用共享前缀 KV，在 DLM 中导致崩溃；bicache 第一次通过层深选择与动态宽度控制实现安全且高效的共享前缀缓存。它与单请求内缓存方案（如 Fast-dLLM）正交，两者结合可进一步提升吞吐。

### English Summary
bicache consists of offline profiling to build a lookup table mapping a request’s shared prefix ratio to a safe layer depth b (based on cosine similarity threshold τ), and online layer-partitioned caching: shallow layers (≤b) directly reuse cached shared prefix KVs across requests; deep layers (>b) reuse KVs within each request via periodic refresh every ∆ steps. This differs from ARM-style caching (universal reuse) and single-request DLM caching (no cross-request reuse).

## 启发性分析 / Insight Analysis

### 中文概述
- 通过余弦相似度热力图（Fig. 3）揭示：共享前缀 KV 跨请求相似度在浅层（low ℓ）和早期步（small t）较高（>0.9），而在深层和后期步骤降，说明双向注意力在深层造成了显著的上下文漂移。
- 反直觉发现：尽管深层不能跨请求重用共享前缀 KV，但在单请求内仍可通过周期性刷新大幅减少计算，且刷新间隔 ∆（8–64）对吞吐和准确率影响极小（吞吐变化仅 2.5%，准确率变化 1.2%），表明深层 KV 对短时陈旧具有较强容忍度。
- 统计分析（Fig. 4, 5）表明，安全层深度 b 与共享前缀 ratio 呈强正相关（如 ratio=0.9 时 b≈25，ratio=0.8 时 b≈20）。bicache 根据这一规律动态调整，既能保持高吞吐，又能将准确率损失控制在 0–1.8%。
- 消融分析（参数 M, τ, ∆）显示方法在所选取值附近鲁棒：剖析请求数 M=500 时映射稳定，阈值 τ=0.97 时准确率达峰且吞吐变化极小，刷新间隔 ∆=16 为合理选择。

### English Summary
Cosine similarity maps show shallow/early-step KVs remain highly similar across requests, while deep/late-step KVs diverge heavily. Counterintuitively, deep layers tolerate stale KVs well within a request (∆ = 8–64 barely affects accuracy). Safe depth b strongly correlates with prefix ratio, enabling dynamic adjustment. Ablations confirm robustness to meta-parameters (M, τ, ∆).

## 局限性与展望 / Limitations & Future Work

### 中文概述
- 作者承认的限制：
  - 仅在最主要的 DLM 模型 LLaDA 上评估，由于 DLM 生态处于早期，其他架构上的泛化性尚未验证。
  - 实验环境为单张 NVIDIA B200 GPU，未在多种加速器（如 AMD, ASIC, 多 GPU）上进行测试。
- 未提及的重要局限：
  - 剖析阶段需要少量代表性请求，在请求分布剧烈变化时可能需要周期性重新剖析，文中未给出适应机制。
  - 共享前缀缓存仅对前缀完全重复的场景有效，对于部分重叠（如不同的多轮对话历史）无法直接利用，可能浪费缓存容量。
  - 方法基于余弦相似度阈值，完全依赖经验设定，缺乏理论上的保证。
- 未来方向：
  - 扩展到更多 DLM 架构（如 MDLM, Plaid 1.5）和异构硬件。
  - 设计自适应剖析策略以应对非平稳请求流。
  - 结合结构化稀疏或量化以进一步压缩 KV 缓存。

### English Summary
Limitations: evaluated only on LLaDA and a single GPU; profiling requires stationary request patterns; no handling of partially shared prefixes; empirical threshold lacks theoretical guarantees. Future work includes broader architecture/accelerator evaluation, adaptive profiling, and integration with structured sparsity.

## 个人思考 / Personal Takeaways

- **方法简洁有效**：bicache 抓住了“双向注意力仅在深层造成显著漂移”这一核心特性，用极简的层划分 + 周期刷新方案就达到了接近无缓存能力的吞吐上限，同时保住了精度。这种“部分重用”思想对后续 DLM 推理优化有很强的启发意义。
- **工程落地潜力**：bicache 与现有单请求缓存（Fast-dLLM）正交兼容，叠加后吞吐再提升 51.6%–98.3%，说明它是一种模块化优化，易于集成到实际服务系统中。此外，500 个请求的剖析代价很低，上线门槛不高。

## 动机 / Motivation

### 中文概述
- 核心问题：扩散语言模型（DLM）使用双向注意力，任何 token 更新都会动态改变整个上下文的 KV 表示。传统的自回归模型（ARM）共享前缀缓存假设 KV 一经计算即不变，若直接搬到 DLM 上会导致模型精度崩溃至近零值。
- 现实需求：实际部署中共享前缀（系统提示、多轮对话历史）占总请求 token 的 85–97%，不解决跨请求的 prefix KV 重用将严重制约 DLM 服务吞吐。现有 DLM 缓存方案（如 Fast-dLLM）仅处理单请求内 KV 重用，未触及跨请求共享前缀这一关键场景。
- 关键观察起点：分析发现共享前缀 KV 在浅层仍能跨请求保持较高相似度；且安全可重用的层深度与请求中共享前缀 token 的占比高度相关，这为选择性的“浅层重用”提供了直接依据。

### English Summary
In DLMs, bidirectional attention causes KVs of the shared prefix to change across denoising steps and requests, so ARM-style caching (which assumes invariant KVs) leads to accuracy collapse. Shared prefixes dominate real workloads (85–97% of tokens), yet no existing DLM cache supports cross-request prefix reuse. The paper’s starting point is the observation that shallow-layer shared prefix KVs remain similar across requests, and the safe reuse depth correlates with the prefix ratio.

## 核心方法 / Core Method

### 中文概述
- 整体框架：bicache 包含离线剖析与在线服务两阶段。先通过少量代表性请求构建“请求共享前缀 ratio → 安全层深度 b”的查找表，然后在实时服务中根据每个请求的 ratio 动态划分浅层与深层，对不同深度的层采取不同的 KV 复用策略。
- 核心机制：
  1. **共享前缀剖析 (Shared Prefix Profiling)**：用 M=500 个请求，计算不同层和步上共享前缀 KV 的跨请求余弦相似度。设定相似度阈值 τ（如 0.97），对于每一个共享前缀 ratio，统计从底层向上第一个使相似度低于 τ 的层作为安全深度 b，由此建立 ratio→b 的映射。
  2. **分层分区缓存 (Layer-Partitioned Caching)**：在服务时，层 1 到 b 的**浅层**直接复用预先计算并缓存的共享前缀 KV（跨请求重用）；层 b+1 到 L 的**深层**采用**周期性刷新 (periodic refresh)**——每 ∆ 步重新计算一次 KV，并在 ∆ 步内跨步骤复用，减少冗余计算的同时避免误差累积。
- 与已有工作的区别：相比 vLLM 在所有层和所有步无差别重用共享前缀 KV，bicache 通过区分深浅层实现了安全重用；相比 Fast-dLLM 等仅限单请求内缓存的方法，bicache 首次支持跨请求的共享前缀缓存，且两者可正交叠加，实现更高吞吐。

### English Summary
bicache first builds, via offline profiling on 500 requests, a lookup table from a request’s shared prefix ratio to a safe layer depth b (using cosine similarity threshold τ=0.97). During online serving, layers 1…b directly reuse cached shared prefix KVs across requests; deeper layers reuse KVs within a request by recomputing them every ∆ steps (periodic refresh). This is the first approach to enable safe cross-request shared prefix caching for DLMs, and it is orthogonal to single-request DLM caching.

## 启发性分析 / Insight Analysis

### 中文概述
- **相似度热力图揭示漂移规律**（Fig. 3）：共享前缀 KV 跨请求的余弦相似度在浅层和早期步较高（>0.9），在深层和后期步骤降。这从数值上证实了双向注意力主要使深层表示产生显著跨上下文漂移，而浅层表示相对稳定。

### English Summary
Similarity heatmaps show KVs in shallow layers remain highly similar across requests, while deep-layer KVs drift significantly. Surprisingly, deep layers tolerate stale KVs within a request (periodic refresh with ∆=8–64 barely hurts accuracy). The safe depth b correlates strongly with the shared prefix ratio, enabling dynamic depth selection. Ablations confirm robustness to profiling size M, threshold τ, and refresh interval ∆.

## 个人思考 / Personal Takeaways

- **核心思想可以泛化**："浅层可重用、深层需刷新"的二分法可能不仅适用于 DLM，对其他采用双向注意力（或非因果注意力）的模型（如 Masked Language Model 的推理优化）也可能有借鉴意义，值得跟踪。
- **工程实用性强**：bicache 的离线剖析成本低（500 个请求即可），与正交加速方案叠加效果显著（+Fast-dLLM 后吞吐再提升 50% 以上），且对超参数不敏感，使其具有较强的生产部署潜力。
- **值得深挖的理论问题**：为什么浅层的 prefix KV 能保持跨请求相似？这是否与注意力模式在浅层更局部、深层更全局有关？若能给出理论解释，可能设计出更具普适性、无需超参的缓存方案。
- **对未来 DLM 系统研制的启示**：本文首次证明了 DLM 也能高效进行共享前缀缓存，消除了一个重要的实用性疑虑。随着 DLM 模型逐渐成熟，类似 LLM 的系统优化（如连续批处理、前缀树复用）都会面临双向注意力带来的新挑战，bicache 提供的分层思路可作为解决这些问题的基线方案。

## 核心方法 / Core Method

### 中文概述
Prisma-World 基于预训练的 Wan2.2-TI2V-5B 模型，将所有智能体的视频帧展平为一个联合 token 序列，在**单次全注意力去噪**过程中一起生成。核心技术包括：
1. **MA-RoPE（多智能体旋转位置编码）**：在空间维度为每个智能体分配独立坐标，同时在时间维度保持所有智能体在同一帧同步，使得注意力机制既能区分智能体身份，又能保持时间对齐。
2. **相机感知交叉视角一致性建模**：在 DiT 的自注意力旁新增一个并行注意力层，将相对相机变换矩阵注入 queries 和 keys，使得邻近视角自动建立更强的关联，从而在几何上约束重叠区域的内容一致性。
3. **重叠衰减课程训练**：从高视觉重叠的训练样本开始，逐渐过渡到复杂、独立轨迹的样本，让模型先学会跨视角对齐，再适应多样轨迹。
4. **动态噪声调整**：根据智能体数量线性调整 flow-matching 的噪声强度，缓解不同 token 长度下的训练难度差异。
5. **迷你地图结构引导（可选）**：将全局自顶向下布局编码后，根据智能体坐标提取局部特征注入对应 token，为生成提供明确的空间先验。

- **将多视角生成转化为联合去噪是一个干净的范式**，解决了“独立采样同一世界”的根本矛盾，有望成为后续多智能体视频世界模型的标准架构。

- 相机相对位姿注入注意力是一种**软几何约束**，比强行施加视图合成损失更优雅，避免了可微渲染的复杂性。这个思想可以移植到其它需要多视角一致性的生成任务（如 3D 重建、多相机视频理解）。
- 课程学习的重叠度衰减策略揭示了训练信号密度的重要性：早期强重叠提供了稠密的跨视角对齐监督，后期稀疏重叠迫使模型泛化。这提示我们在多智能体训练中，**数据配比和调度远比模型容量重要**。
- 当前工作停留在“同一场景不同视点”的生成，尚未涉及智能体之间的交互行为（如对话、协作），未来若能结合语言模型的动作控制，将真正迈向多智能体世界模拟。
- 自建数据集是这篇工作的另一大贡献，全景采集＋投影透视的组合策略可以低成本构造任意多视角数据，对于缺乏大规模多智能体数据的领域极具参考价值。
- 不足：缺少详尽量化实验和理论解释（例如为什么相机几何注入注意力能 work），论文更像一个系统设计，验证深度有待加强。
